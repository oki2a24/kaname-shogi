# 対局形式とCLI担当設定の知識メモ

更新日：2026-09-27

- 将棋規則は先手が開始し、先後が交互に着手することを定める。これは`Position.side_to_move`と既存の局面適用が担う。
- `GameMode`は「誰が入力・自動手を担当するか」を表すCLI進行用のデータで、局面や手番を変更しない。
- 対象は人間対人間、人間対コンピュータ（先手人間）、コンピュータ対コンピュータの三形式だけである。
- `run_game()`の既定値は人間対コンピュータであり、既存利用者の振る舞いを保つ。固定種の`random.Random`は一局の全自動手で共有し、人間手では消費しない。
- 成功した盤上移動・駒打ちだけが`GameRecord.moves`に入る。投了、EOF、Ctrl-C、詰み、合法手空一覧、メニュー選択は入らない。
- コンピュータ対コンピュータは詰み、合法手空一覧、Ctrl-Cで停止する。千日手・持将棋・手数上限は未実装なので、長時間または無限に続く可能性がある。

出典：[日本将棋連盟「対局規則」](https://www.shogi.or.jp/match/taikyoku_rules/taikyoku_rules.pdf)
