# 詰み・終局判定：参照メモ

更新日：2026-09-23

## 将棋の規則

- 詰みとは、次にどのように応対しても玉が取られることを防げない状態である。
- 対局は詰みまたは相手の投了で終了する。入玉や反則などでも終局する場合がある。
- 王手を防ぐ方法には、玉を逃がす、王手駒を取る、飛車・角・香の直線王手なら間へ駒を置く合い駒がある。桂馬は飛び越えるため合い駒では防げない。
- 打ち歩詰めは反則であるが、今回の対象外とする。したがって今回の「合法手」は、現在実装済みの規則で受け入れられる手を指し、完全な将棋規則の合法手ではない。

出典：[日本将棋連盟「対局規則」第2条・第6条・第10条](https://www.shogi.or.jp/match/taikyoku_rules/)、[日本将棋連盟「王手と詰み」](https://www.shogi.or.jp/knowledge/shogi/04.php)、[日本将棋連盟「反則について」](https://www.shogi.or.jp/knowledge/shogi/05.php)

## プログラム上の接続

- `has_legal_move(position)` は、手番側の全盤上駒の移動先候補、不成・成り、玉以外の持ち駒の全打ち先を、複製局面で `apply_move` と `apply_drop` により試す判定操作である。渡された局面は変更しない。
- 試行中の `ValueError` は、その候補が既存規則により指せないことを表す。成り、駒取り、二歩、行き所のない駒、王手放置は既存の適用操作へ委譲し、再実装しない。
- `is_checkmate(position)` は、手番側の玉があり、`is_in_check` が真で、`has_legal_move` が偽のときだけ真を返す判定操作である。
- `is_game_over(position)` は、今回の範囲では詰みだけを終局として `is_checkmate` と同じ結果を返す。投了・千日手・持将棋・入玉・時間切れ・反則勝敗は含めない。
- 玉がない部分局面と、王手でない合法手なし局面は、詰み・終局とも偽とする。

## 今回の対象外

打ち歩詰め、合法手一覧や指し手値の導入、投了、千日手、持将棋、入玉、時間切れ、反則勝敗、CLI入力、履歴、評価、探索、USI/SFENは扱わない。
