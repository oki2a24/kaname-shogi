# 打ち歩詰め：参照メモ

更新日：2026-09-23

## 将棋の規則

- 日本将棋連盟の対局規則第10条第1項三は、打ち歩詰めを「持ち駒の歩を打って解除不能な王手をかける行為」と定め、反則者の即負けとしている。
- 対象は持ち駒の歩を打つ操作だけである。盤上の歩の移動、歩以外の駒打ちによる詰みは打ち歩詰めではない。
- 打った歩が王手をかけても、玉が歩を取れる、玉が安全なマスへ逃げられる、別の合法手で王手を解除できる場合は打ち歩詰めではない。
- 玉なし部分局面は、既存の `is_checkmate` と同じく詰みではない `False` とする。

出典：[日本将棋連盟「対局規則」第10条](https://www.shogi.or.jp/match/taikyoku_rules/)

## プログラム上の接続

- `apply_drop(position, piece_type, destination)` は、既存の駒打ち規則と自玉安全を複製局面で確認した後、持ち歩の場合だけ相手番の詰みを調べる。詰みなら `ValueError` とし、本物の局面を変更しない。
- `has_legal_move(position)` は、打ち歩詰めとなる歩打ちを合法手に数えない。局面の盤面、持ち駒、手番は変更しない。
- `is_checkmate(position)` は詰みの真偽を返す操作であり、打ち歩詰めそのものを返り値として判定する操作ではない。ただし合法手探索から打ち歩詰めを除外する。

## 循環回避

公開操作をそのまま相互に呼ぶと、`apply_drop → is_checkmate → has_legal_move → apply_drop` の再入経路ができる。そこで非公開操作に `check_uchi_fuzume` を設け、外側の駒打ちと通常の合法手探索では `True`、外側の打ち歩詰め確認中の応手探索では `False` とする。無効にするのは再度の打ち歩詰め確認だけで、二歩、行き所のない駒、自玉安全など既存規則は確認する。
