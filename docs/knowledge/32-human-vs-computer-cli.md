# 人間対コンピュータのCLI進行：参照メモ

## 既定の担当と開始

`python3 -m kaname_shogi` は、人間を先手、コンピュータを後手として開始する。人間の成功手後にコンピュータが一手を選び、適用する。手番ごとの担当判定をCLI内部の境界に置き、将来の担当切替をその境界へ集約する。

## 乱数

`run_game`は`random.Random`を任意に受け取る。省略時は対局開始時に一個だけ生成し、その局の全自動手で使い回す。固定種を注入すれば、同じ局面と入力に対する自動手列を再現できる。

## 表示

開始盤面、人間入力案内、人間成功手後の盤面、`後手の指し手: ...`、コンピュータ成功手後の盤面、次の人間入力案内の順で表示する。形式・合法性エラーでは盤面と手番を変えず、人間へ再入力を求める。

## 終了と記録

各手番の前に既存の`is_game_over`で詰みを判定する。詰みでないコンピュータの合法手空一覧は、`None`を勝敗や投了と解釈せず、勝敗なしで終了する。投了は人間の`resign`だけで、EOF/Ctrl-Cは勝敗なしの入力中断である。

人間・コンピュータ双方の成功した`move` / `drop`だけを、既存の`GameRecord`へ手番順に記録する。担当者情報と終局理由は履歴・JSON保存形式へ追加しない。

出典：[日本将棋連盟「対局規則」](https://www.shogi.or.jp/match/taikyoku_rules/)
