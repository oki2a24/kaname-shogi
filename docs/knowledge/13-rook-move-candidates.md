# 飛車の移動先候補：参照メモ

## 動き

- 成る前の飛車は、同じ筋の前後と同じ段の左右へ任意のマス数進める。
- 4方向を別々に調べる。ある方向が塞がっても他方向は調べる。
- 空マスは候補に含め、走査を続ける。
- 自駒のマスは候補に含めず、その方向を止める。
- 相手駒のマスは候補に含め、その方向を止める。

## 今回の対象外

成り、竜の動き、実際の移動、駒取り、持ち駒、王手、合法手判定、手番による制限は扱わない。
