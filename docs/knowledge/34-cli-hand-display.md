# 対局中の持ち駒表示

更新日：2026-10-01

- `Position.sente_hand` と `Position.gote_hand` は双方の持ち駒枚数を保持する。表示は `render_position(position)` が `Hand.count()` で読み取り、局面を変更しない。
- 先手視点の盤表示では、後手の持ち駒を盤の上、先手の持ち駒を盤の下に表示する。手番・対局形式によらず双方を表示する。
- 0枚は「なし」と表示する。
- 持ち駒がある場合は、歩・香・桂・銀・金・角・飛の順に並べる。各枚数は1枚の場合も省略しない。
- 表示責務は `kaname_shogi/display.py` にあり、CLI進行やモデルに依存した表示処理を追加しない。

出典：[日本将棋連盟「対局規則」](https://www.shogi.or.jp/match/taikyoku_rules/)。同規則第3条第2項は盤の隣で各自から見た右側への持ち駒配置、第5条第2項・第3項は駒取りと持ち駒の使用を定める。文字CLIでの上下配置、駒種順、枚数表記は本テーマの表示設計である。
