# 金の移動先候補：参照メモ

## 動きと座標

- 金は前・斜め前の左右・横の左右・真後ろへ各1マス動ける。斜め後ろには動けない。
- 前後は所有者を基準にする。先手の前は段−1、後手の前は段＋1。
- ５五→５四では筋は５のまま、段が五から四へ変わる。

## 候補計算で扱うこと

- 動きに合う移動先から、盤外と自駒のいるマスを除外する。
- 空マスと相手駒のいるマスは候補に含める。王手などを確認していないため、合法手の確定ではない。
- 候補を調べるだけでは盤面を変更しない。相手駒を候補に含めても、まだ取らない。
- 同じ元の盤面で各候補を調べる。状態の保存・復元はプログラム上可能だが、今回の候補計算では不要。

実装は `gold_move_candidates(board, source)`。戻り値は新しいリストで、前・前方の筋＋1・前方の筋−1・横の筋＋1・横の筋−1・真後ろの順。空または金以外の出発点はValueError。歩との共通化は見送り、詳細は[実装設計](../design/03-gold-move-candidates.md)を参照する。
