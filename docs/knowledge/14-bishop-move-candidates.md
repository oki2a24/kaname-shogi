# 角の移動先候補：参照メモ

## 動き

- 成る前の角は、斜め4方向へ任意のマス数進める。
- 4方向を別々に調べる。ある方向が塞がっても他方向は調べる。
- 空マスは候補に含め、走査を続ける。
- 自駒のマスは候補に含めず、その方向を止める。
- 相手駒のマスは候補に含め、その方向を止める。

## 飛車との共通点と相違点

- 共通点：複数方向へ1マスずつ走査し、盤外または駒に当たった地点でその方向を終了する。
- 相違点：飛車は縦横4方向、角は斜め4方向へ進む。

## 今回の対象外

成り、馬の動き、実際の移動、駒取り、持ち駒、王手、合法手判定、手番による制限は扱わない。
