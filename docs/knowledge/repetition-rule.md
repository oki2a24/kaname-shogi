# 千日手判定と履歴

## 現在の実装契約

- 同一局面の比較対象は81マスの駒種・所有側、先後双方の持ち駒、手番。棋譜手数やSFENの手数欄は含めない。
- 開始局面を一回目として数え、成功した実着手後の局面だけを追加する。不正手、探索中の仮想局面、終了イベントは履歴へ含めない。
- 通常の4回目は通常CLIで続行し、打開後に同じ局面が再出現した時点で終了する。連続王手なら、その区間で王手を続けた側が負ける。5回目の区間には同一局面の直近4回を使う。
- 双方が同じ区間の全着手で王手を続けた場合、確認した一次資料に裁定がないため、勝者を作らず未裁定として停止する。
- 棋譜読込時は開始局面と全指し手を再生して履歴を復元する。千日手成立後の指し手が続く棋譜は拒否し、読込前の棋譜と時計を保つ。
- 終局結果は保存せず、既存棋譜v1の開始局面と指し手から再判定する。通常CLIは成立を表示して現在の一局を終了し、自動で指し直さない。

## 適用範囲

通常CLIの人間対人間、人間対コンピュータ、コンピュータ対コンピュータの実対局履歴が対象。比較CLI、USI、探索中の反復、通常CLIのSFEN局面開始、早期合意による指し直しは対象外。

4回目の通常出現後も指し継ぐこと、5回目では直近4回の区間を調べること、双方連続王手を勝者なしで停止することは、本人が選んだ実装上の扱いである。公式対局の指し直し規則と混同しない。
