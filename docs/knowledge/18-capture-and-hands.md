# 駒取りと持ち駒

更新日：2026-09-22

## 将棋のルール

相手の駒があるマスへ進むと、その駒を取る。取った駒は盤上から取り除かれ、取った側の持ち駒になる。持ち駒は盤上の筋・段を持たない。日本将棋連盟は、取った駒を持ち駒と呼び、原則として空いているマスへ打てると説明している。[日本将棋連盟「駒の動かし方」](https://www.shogi.or.jp/knowledge/shogi/02.php)

## この段階の表現

- `Hand` は一方の持ち駒の枚数を表す可変のデータ。先手・後手、盤面、手番は知らない。
- `Position` が `sente_hand` と `gote_hand` の二つの `Hand` を持つ。各局面と先後の持ち駒は独立している。
- `Hand.count(piece_type)` は枚数を読む操作、`Hand.add(piece_type)` は1枚加える操作である。玉はどちらの操作でも受け付けない。
- `apply_move(position, source, destination)` は、候補に含まれる相手の玉以外の駒を取ると、出発マスを空にし、指した駒を到着マスへ置き、取った基本駒種を手番側の `Hand` へ1枚加え、手番を交代する。
- 失敗時（候補外、所有者不一致、空出発、自駒の到着、玉取りなど）は、盤面・手番・双方の持ち駒を変更しない。

## まだ扱わないこと

持ち駒を打つ操作と打ち場所の制限、成り・不成、成駒を取ったときに基本駒種へ戻す処理、王手・詰み・合法手判定、対局履歴、CLI入力、評価・探索は次の段階以降に分ける。

設計理由と正確な契約は[駒取りと持ち駒の設計](../design/13-capture-and-hands.md)を参照する。
