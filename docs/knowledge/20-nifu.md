# 二歩：参照メモ

更新日：2026-09-22

## 将棋のルール

同じ筋に自分の未成の歩があるとき、その筋へ持ち歩をもう1枚打つことは二歩という反則である。成った歩であると金と同じ筋へ歩を打つことは二歩ではない。[日本将棋連盟「反則について」](https://www.shogi.or.jp/knowledge/shogi/05.php)

## この段階の表現

- `apply_drop(position, piece_type, destination)` は、歩を打つときだけ二歩を調べる局面操作である。
- 打ち先の `destination.file` と同じ筋に、`position.side_to_move` が所有する未成の歩があれば `ValueError` とする。
- 二歩の失敗時は、盤面・手番・先後双方の持ち駒を変更しない。
- 現在は成り状態を表現しないため、盤上の `PieceType.PAWN` を未成の歩として扱う。と金の表現と除外は、成りを実装する回に見直す。

## まだ扱わないこと

行き所のない歩・香・桂、打ち歩詰め、成り・不成、王手・詰み・合法手判定、CLI入力、対局履歴は後続のテーマに分ける。

設計理由と正確な契約は[二歩の設計](../design/15-nifu.md)を参照する。
