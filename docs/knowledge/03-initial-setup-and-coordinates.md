# 初期配置と盤上の座標：実装用メモ

## 座標

将棋のマスは、筋（`1`〜`9`）と段（`1`〜`9`。表記では一〜九）の組で表す。先手から見た盤では、`９九` が左下、`１一` が右上である。

内部座標系は実装で選ぶ。左下原点・0始まりの配列座標に対応付ける場合は、次の変換が一貫する。

```text
x = 9 - file   // file は将棋の筋（1〜9）
y = 9 - rank   // rank は将棋の段（1〜9）
```

このとき `９九` は `(0, 0)`、`１一` は `(8, 8)` になる。別の座標系を採用してもよいが、盤面表示・駒の移動・SFENなどで混同しないよう、変換規則を1か所に集約する。

## 最初の実装への対応

- `Square` は `file` と `rank` を持つ値オブジェクトにする。各値が1〜9の範囲にあることを検証できるようにする。
- `Board` は81マスを保持し、`Square` から内部添字へ変換して駒を取得・配置する。
- `createInitialPosition()` は上表の40枚を配置し、先手を手番に設定する。
- 初期配置をテストする際は、代表例だけでなく、各側の駒数20枚・両側の歩9枚・玉と王の位置を確認する。
