# 将棋の全体像：実装用メモ

## ルールの最小要約

| 項目 | 将棋のルール | 実装上の対応 |
| --- | --- | --- |
| 目的 | 相手の玉を詰ます。詰みは、どの応答でも次に玉を取られることを防げない状態。 | `isCheckmate(position, side)` を終局判定の中心にする。玉を実際に取る手は生成せず、王手と合法応答の有無で判定する。 |
| 盤 | 9×9の81マス。 | `Board` は9行×9列、または0〜80の81要素で表す。座標の向きは早期に固定する。 |
| 手番 | 最初に指す側が先手、次が後手。 | `Side` を `Sente` / `Gote` の2値で持ち、指し手の適用後に反転する。 |
| 駒 | 玉（王）、飛、角、金、銀、桂、香、歩の8種類。 | `PieceType` を8種類の列挙値で表し、盤上の駒には所有者（`Side`）も保持する。 |

## 駒の種類

日本将棋連盟の対局規則で定められる開始時の8種類は、玉将（または王将）、飛車、角行、金将、銀将、桂馬、香車、歩兵である。略記は順に玉（王）、飛、角、金、銀、桂、香、歩。[対局規則 第3条](https://www.shogi.or.jp/match/taikyoku_rules/)

実装名の候補は次のとおり。

| 表示名 | 実装名の候補 | 開始時の各側の枚数 |
| --- | --- | ---: |
| 玉／王 | `King` | 1 |
| 飛 | `Rook` | 1 |
| 角 | `Bishop` | 1 |
| 金 | `Gold` | 2 |
| 銀 | `Silver` | 2 |
| 桂 | `Knight` | 2 |
| 香 | `Lance` | 2 |
| 歩 | `Pawn` | 9 |

## 実装時の注意

- 玉将と王将は同じ動き・役割の駒であり、対局ごとに表記が異なるだけである。内部表現は `King` の1種類でよい。[日本将棋連盟「駒の動きと特徴」](https://www.shogi.or.jp/knowledge/shogi/03.php)
- 8種類は「成る前」の種類である。飛・角・銀・桂・香・歩は成ると別の動きを持つため、後続の実装では成り状態も表現する。玉と金は成らない。[日本将棋連盟「駒の動きと特徴」](https://www.shogi.or.jp/knowledge/shogi/03.php)
- 駒の具体的な移動規則、持ち駒、成り、王手・合法手の詳細は別テーマで扱う。この文書では盤・手番・駒種・勝敗の骨格だけを固定する。
