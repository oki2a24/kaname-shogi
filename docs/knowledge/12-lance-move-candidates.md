# 香の移動先候補：参照メモ

## 動きと座標

- 成る前の香は前方だけへ複数マス進める。途中の空マスで止まることもできる。
- 筋は変わらない。先手の前は段−1、後手の前は段＋1。
- ほかのマスが空なら、５五の先手の香の候補は５四・５三・５二・５一。後手なら５六・５七・５八・５九。
- 自駒も相手駒も飛び越せない。相手駒を取った後、同じ一手でさらに進むこともできない。

## 前方を調べる際の扱い

| 調べた場所 | 候補への追加 | その先を調べるか |
| --- | --- | --- |
| 空マス | 含める | 続ける |
| 自駒のマス | 含めない | 止める |
| 相手駒のマス | 含める | 止める |
| 盤外 | 含めない | 止める |

- 先手の香が５五、自駒が５三なら候補は５四だけ。５三が相手駒なら５四・５三。
- 盤の端の確認用に、先手の成る前の香を一段に置いた場合は候補なし。これは実戦の合法な配置を示す例ではない。
- 候補計算は盤面を変えない。相手駒のマスを候補に含めても、実際には駒を取らない。
- 成香、成りの選択、実際の移動・駒取り、持ち駒、王手・合法手判定、探索は今回の対象外。

## 学習後に合意した実装

- `lance_move_candidates(board, source)` は香の移動先候補を求める操作。Boardは盤面データ、Squareはマスの値。
- 所有者は出発点の香から読む。前方を近い順に調べ、新しいリストで返す。候補なしは空リスト、空・香以外の出発点はValueError。
- 手番に依存せず、盤面を変更しない。飛・角との共通化は先取りせず、香専用の短い関数で停止条件を表す。
