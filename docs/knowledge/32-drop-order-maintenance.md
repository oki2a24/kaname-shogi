# 駒打ち順を公開API契約として保守する知識メモ

更新日：2026-09-26

## 規則と実装契約

- 日本将棋連盟の対局規則は、持ち駒を反則に該当しない空きマスへ置けることを定めるが、合法手一覧の列挙順は定めない。
- `legal_moves(position)` の駒打ち順「飛・角・金・銀・桂・香・歩」は、将棋規則ではなく、テストと固定種の乱数選択を再現可能にする本プログラムの公開API契約である。

## 順序の表現

- `BasicPieceType` は持ち駒の種類を表すデータである。定義順・列挙値・成駒からの復元の役割を変更しない。
- `kaname_shogi/movegen.py` の非公開 `_DROP_PIECE_TYPES` は、合法手一覧での駒種順を表す順序表である。
- 各駒種内の打ち先は、筋1から9、各筋の段1から9の順で、既存の合法性判定により打てない段を除く。

## 確認方法

- 空盤面に手番側の飛・角・金・銀・桂・香・歩を各1枚持たせ、先手・後手それぞれで一覧全体を期待値と比較する。
- 先手・後手の歩・香・桂の行き所のない段を確認する。
- 列挙前後で盤面、両者の持ち駒、手番が変わらないことを確認する。
- `BasicPieceType`の反復順を一時的に変えても公開順が変わらないテストで、実装の直接反復依存を防ぐ。
- 二歩、自玉の安全、打ち歩詰めなど既存合法性テストを回帰確認する。

出典：[日本将棋連盟「対局規則」](https://www.shogi.or.jp/match/taikyoku_rules/taikyoku_rules.pdf)
