# 成駒の移動：参照メモ

更新日：2026-09-23

## 駒の動き

- と金（`PRO_PAWN`）、成香（`PRO_LANCE`）、成桂（`PRO_KNIGHT`）、成銀（`PRO_SILVER`）は金と同じ6方向へ1マス進む。
- 馬（`HORSE`）は角と同じ斜めの長距離移動に加え、縦横へ1マス進む。
- 竜（`DRAGON`）は飛車と同じ縦横の長距離移動に加え、斜めへ1マス進む。
- 長距離移動は駒を飛び越せず、最初の相手駒のマスは候補に含め、自駒のマスとその先は含めない。
- 候補生成は盤面を変更せず、王手・合法手を判定しない。

出典：[日本将棋連盟「駒の動きと特徴」](https://www.shogi.or.jp/knowledge/shogi/03.php)

## プログラム上の接続

- `PieceType` は6種類の成駒を盤上のデータとして表す。
- `movegen.py` の成駒候補関数は、盤上の `Piece.side` から前後を決める操作である。
- `apply_move` は候補内の成駒を同じ `PieceType` のまま移動し、相手駒を取ったときだけ `base_piece_type` で基本駒種に戻して持ち駒へ加える。
- 成駒に `promote=True` を指定することはできない。
