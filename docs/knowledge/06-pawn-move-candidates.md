# 歩の移動先候補：実装用メモ

第6回で合意した範囲。[学習・調査の背景](../learning/06-pawn-move-candidates.md)を参照する。関数のAPIとテスト設計は未承認、コードは未実装。

## 候補の条件

筋は変えず、先手は段−1、後手は段＋1を計算する。

| 一歩前の状態 | 候補に含めるか |
| --- | --- |
| 盤外 | 含めない |
| 空マス | 含める |
| 自分の駒 | 含めない |
| 相手の駒 | 含める |

盤外は通常の「候補なし」として扱い、`Square` を作る前に除外する。`Square` の不正値検証も維持する。これは今回の設計方針であり、全エンジン共通の必須実装方式ではない。

## 責務の境界

- 候補計算は盤面と手番を変更しない。
- 指し手の適用、駒取りの実行、持ち駒への追加は別の処理。
- 成り、王手・王手放置、その他の合法手判定は対象外。相手駒のマスを含むことは、玉取りなどを合法と認める意味ではない。
- 現在持ち駒はデータ構造自体が未実装。今回先取りして追加しない。

## 設計で決めること

関数名、引数、戻り値、出発点に歩がない場合の扱い、手番との関係、確認するテストケース。
