# リポジトリ基盤整理ロードマップ

作成日：2026-09-27

## 目的

CLIで弱くても対局でき、明示的な保存・読込もできるという最初の目標を達成した時点で、次の機能追加の前にリポジトリの土台を整理する。人間が現在地と利用方法を読み取りやすく、AIが確定仕様・経緯・作業規律を誤解なく参照しやすい文書構成を目指す。同時に、プログラムコードとユニットテストの責務・依存・規模を点検し、必要な改善だけを小テーマに分けて実施する。

これは一回で大規模に書き換える作業ではない。各テーマを別セッションで一つずつ扱い、調査・設計・承認・実装・検証・レビューの境界を守る。
