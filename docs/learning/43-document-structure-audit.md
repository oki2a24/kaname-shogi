次の機能追加へ進む前に、増加した文書の役割、読み手、入口、更新契機を棚卸しする。

今回はコード、テスト、README、既存文書の構造を変更せず、棚卸し、確認問題、
改善対象の優先順位、設計仕様の承認までを扱う。
