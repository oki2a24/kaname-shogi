# 第8回：金の移動先候補

## 学習の目的

金の動きを筋・段で表し、歩で学んだ候補の除外条件を複数の移動先へ広げて考える。2026-09-14に利用者がテーマに同意した。今回は学習から始め、実装の設計はまだ行わない。

## 要点

- 金は前、斜め前の左右、横の左右、真後ろの計6方向へ、それぞれ1マス動ける。斜め後ろには動けない。
- 前後は駒の所有者を基準にする。先手の前は段が減る向き、後手の前は段が増える向き。

## 確認問題・回答

1. 先手の金が５五にあり、周囲のマスがすべて空の場合、金の動きだけを考えた移動先候補はどのマスか。筋・段で全部挙げる。
   - 本人の回答：「5四、6四、4四、6五、4五、5六」
   - 評価：正解。6マスを過不足なく挙げられた。
   - アシスタントの補足：５四・６四・４四が前方、６五・４五が横、５六が真後ろに当たる。
2. 後手の金が５五にあり、周囲のマスがすべて空の場合、金の動きだけを考えた移動先候補はどのマスか。筋・段で全部挙げる。
   - 本人の回答：「6六、5六、4六、6五、4五、5四」
   - 評価：正解。後手の向きで6マスを過不足なく挙げられた。
   - アシスタントの補足：６六・５六・４六が前方、６五・４五が横、５四が真後ろに当たる。
3. 先手の金が１一にあり、ほかのマスがすべて空の場合、金の動きと盤の範囲だけを考えた移動先候補はどのマスか。筋・段で全部挙げる。
   - 本人の回答：「2一、1二」
   - 評価：正解。盤外を除外し、盤内の2候補を過不足なく挙げられた。
   - アシスタントの補足：２一が横、１二が真後ろ。２二は盤内だが、先手の金にとって斜め後ろなので候補に含めない。
4. 先手の金が５五、先手の歩が５四にあり、ほかのマスがすべて空の場合、金の移動先候補はどのマスか。王手は考えず、筋・段で全部挙げる。
   - 本人の回答：「6四、4四、6五、4五、5六」
   - 評価：正解。自駒のいる５四だけを除外し、残る5候補を過不足なく挙げられた。
   - アシスタントの補足：自分の駒がいるマスへは進めないため、５四を候補から除く。
5. 先手の金が５五、後手の歩が５四にあり、ほかのマスがすべて空の場合、５四は金の移動先候補に含まれるか。王手は考えず、理由も答える。
   - 本人の回答：「含まれる。金は筋を一つ前に進むことができ、その場所には後手の駒があるため」
   - 評価：候補に含める判断と、相手駒の扱いは正しい。「筋を一つ前」は用語の補足が必要。
   - アシスタントの補足：５五から５四では筋は５のまま、段が五から四へ変わる。「段を一つ減らして前へ進む」と表せる。金が動けるマスに相手駒があるため、取る移動の候補に含める。
6. 先手の金が５五、後手の歩が５四にある状態で、５四を移動先候補として返しただけの場合、盤上の金と歩はそれぞれどこにあるか。
   - 最初の本人の回答：「先手の金が5四にいる状態になる。後手の歩は5四から5四つまり同じ場所に移動することはできないので、先手の金が移動したことになる。後手の歩は取られて」
   - アシスタントの補足：これは実際に金を動かして歩を取った場合の説明。候補を調べただけでは盤面を変更しないため、金は５五、後手の歩は５四に残り、歩もまだ取られない。
   - 再確認：５四へ動けると候補を調べた後、まだ手を選んでいないなら、先手の金はどこにあるか。
   - 再確認への本人の回答：「5五にあるままとなる」
   - 評価：説明後に金が出発マスに残ることを確認できた。最初から正解したとは記録しない。後手の歩についての本人による再回答はまだない。
7. 候補を調べる処理で実際に駒を動かしてしまうと、ほかの移動先候補を同じ盤面で調べるときに、どんな困りごとが起きるか。
   - 本人の回答：「時間は戻せないので、動かしてしまうと他の移動先候補が調べられなくなる」
   - 評価：元の盤面が変わると同じ条件でほかの候補を調べられない、という問題は捉えている。ただし、プログラム上の状態を元に戻せないわけではない。
   - アシスタントの補足：元の状態を保存して復元したり、盤面のコピーを使ったりすることは可能。今回の候補計算は最初から盤面を変更せず、５五に金がある同じ状態で各移動先を調べるため、復元処理は不要。

## 振り返り

先手・後手の金について、6方向の動きを筋・段で正しく表せた。盤の端でも盤外を除いた候補を挙げられ、自駒のいるマスも除外できた。相手駒のいるマスを候補に含める判断も正しかったが、前進の説明で筋と段の呼び方に混同があり、補足した。

候補計算と実際の移動は当初混同していた。説明後の再確認では、金が５五に残ると回答できた。盤面を変更するとほかの候補を調べる条件が変わる点は捉えていたが、プログラムでは状態の保存・復元も可能であることを補足した。

- 本人の振り返り：「引っかかっている点はありません。私がせっかちなようです」
- アシスタントの補足：実際に指した後の局面まで考えていたと受け止めた。説明後に候補計算では金が元のマスに残ることを確認できている。

今回はここで学習の区切りとする。確定した要点は[金の移動先候補の参照メモ](../knowledge/08-gold-move-candidates.md)にまとめた。
