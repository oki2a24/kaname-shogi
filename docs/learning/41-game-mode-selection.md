## 一次資料

日本将棋連盟の対局規則第2条は先手開始と交互着手を定め、第10条は先後誤り・二手指しを反則としている。人間かコンピュータかは規則ではなく、このプログラムのCLI設定である。

出典：[日本将棋連盟「対局規則」](https://www.shogi.or.jp/match/taikyoku_rules/taikyoku_rules.pdf)

## 確認問題と合意

1. 指定場所：`run_game`引数と起動メニューの両方にする。本人の回答：良い。
2. 担当：人間対人間は両側、人間対コンピュータは先手人間・後手コンピュータ、コンピュータ対コンピュータは両側コンピュータ。本人の回答：良い。
3. 自動対局の停止：詰み・合法手空・Ctrl-Cだけとし、千日手・持将棋・手数上限は追加しない。本人の回答：Ctrl+Cで可能なら良い。
4. 乱数：一局の自動手で一つを共有し、人間手は消費しない。本人の回答：良い。
5. 投了・EOF：人間担当だけが`resign`とEOFを扱い、全形式でCtrl-Cは勝者なしの中断。成功手だけを記録する。本人の回答：良い。
6. 表示・棋譜：担当に応じた入力案内・自動手表示、盤上移動・駒打ちの順序どおりの`GameRecord`を確認する。本人の回答：良い。
7. 表現：`GameMode`を対局形式を表す公開データにする。本人の回答：良い。
