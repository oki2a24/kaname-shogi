# 成りに近づく進行度の学習

2026-11-04から2026-11-07までの対話の事後記録。開始時の経緯は[引き継ぎ](../handover-promotion-progress-evaluation.md)を参照する。

## 目的と要点

成れる条件を確認し、成駒の現在の価値と、未成駒が将来成る機会を区別する。先読みが成る前で止まる場合に、その機会を評価で補う意味があるかを検討した。

- 成れる種類の盤上の未成駒は、移動元か移動先が敵陣なら成れる。持ち駒は成った状態で打てない。先手の歩が一段目へ進む場合、不成では行き所がない。[日本将棋連盟「対局規則」第4・5・10条](https://www.shogi.or.jp/match/taikyoku_rules/)
- 銀は成ると斜め後ろへの利きを失う。感想戦で示された手順では、７二で銀不成にすると６三への利きが残り、後手玉の逃げ道をふさぐ。[王位戦中継ブログ「本局のハイライト」](https://kifulog.shogi.or.jp/oui/2015/07/post-05b2.html)
- 固定条件の試案では、対象の一枚を駒の動きに従って動かし、成るまでの最短移動回数を数える。他の駒は固定し、取った相手駒だけを盤上から除く。横・後ろへの移動や敵陣から出る成りも含む。相手の妨害、味方による道開け、成った後の安全性はこの試案の回数に含まれない。

## 調査と振り返り

アシスタントの補足。今回確認した一次資料から、固定条件の最短移動回数を評価に使い、有効性を示した例は確認できなかった。やねうら王のHalfKPは玉と他の駒の配置の組み合わせを入力とする。金子・山口の研究は棋譜の手と他の手の先読み後の局面を比較して評価の重みを調整する。やねうら王の作者は、短い先読みで分かる情報を評価側で詳しく計算する場合の費用を指摘している。[HalfKPの実装](https://github.com/yaneurao/YaneuraOu/blob/master/source/eval/nnue/features/half_kp.h)、[金子・山口の研究](https://www.graco.c.u-tokyo.ac.jp/labs/kaneko/kaneko/papers/gpw08.pdf)、[やねうら王公式の解説](https://yaneuraou.yaneu.com/2020/11/30/make-evaluate-function-8/)

固定条件で到達できるか、選択手が変わるか、実際に成ったか、対局成績が変わるかは別々に確かめる。道の違いを区別できることは手計算で確認したが、指し手や対局成績の改善は未検証。既存の駒得評価が扱う成駒の価値や、支えのない被攻撃駒を扱う評価との重なりも、候補を検討する際の確認事項とする。

## 保留の判断（2026-11-07）

追加例では、先手の歩が６五、味方の金が６四にいる。金を５四に動かすAは歩が2回で成れ、６三に動かすBは固定条件では到達できないと本人は回答した。Aの金がただで取られる条件では、別の場所ですぐ同等の駒を取れるなら検討の余地はあるが、埋め合わせがなければもったいないという見方を示した。

本人は、今回の例から他の局面でも役立つか見通しづらいと感じ、候補を保留する判断を示した。成りへの道を開く手を尺度で拾えることは手計算で確認した。再現性や実戦での有用性を実測して判定した段階ではない。対象駒、評価式、係数は未決定で、設計・実装・比較には進んでいない。
