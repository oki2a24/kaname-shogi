## 要点と実装

５五飛で５四歩を取ると直後は得でも、５三金で飛車を取り返される。自分の候補ごとに相手の全応手を試し、自分に最も不利な値を候補の値として比較する。その値が最大の候補を選ぶ。

- `MoveSelectionPolicy` は選択方針のデータ型。既存値を維持して末尾に `TWO_PLY_MATERIAL` を追加した。
- `choose_move` は候補から一手を選ぶ操作。公開名・引数を維持して新方針の分岐を追加した。
- `_position_after_move` は複製へ一手を適用する非公開操作。候補と応手の双方で別々に複製し、移動・駒打ちと例外は既存操作へ委ねる。
- `_two_ply_score` は一手後から全応手後の最小評価を返す非公開操作。開始側視点を固定する。
- `_choose_two_ply_material_move` は最高評価の候補だけを元の順序で集め、一回抽選する非公開操作。

評価は勝ち `(1, 0)`、通常 `(0, 駒得差)`、負け `(-1, 0)`。詰み優先、詰みでない途中手なしの静的評価、空候補None、同点最高だけの抽選、二手での駒得探索停止を設計どおり実装した。これらの境界の網羅テストはタスク2に残る。既存MATERIALの一手限定処理とRANDOMへの委譲、駒価値は変更していない。CLI・USIから新方針を選ぶ機能は未実装。
