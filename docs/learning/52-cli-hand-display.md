# 第52回：対局中の持ち駒表示

## 目的

対局中の局面表示で、先手・後手双方の持ち駒を文字で確認できるようにする。盤面の方向を保ちながら、現在の `Position` と `Hand` の読み取りだけで表示する。

設計は[設計仕様](../plans/2026-10-01-cli-hand-display-design.md)、実装手順は[実装計画](../plans/2026-10-01-cli-hand-display.md)に記録した。

## 一次資料と既存UIの調査

日本将棋連盟の対局規則第3条第2項は、持ち駒を盤の隣で各自から見た右側に置くと定める。第5条第2項・第3項は、取った駒を持ち駒にし、持ち駒を空きマスへ置けると定める。これは持ち駒の意味と実際の配置の根拠であり、CLIの文字配置はこの規則をそのまま再現する必要はない。

- [日本将棋連盟「対局規則」](https://www.shogi.or.jp/match/taikyoku_rules/)

将棋ログのアプリ更新履歴には、駒台を将棋盤の上下に配置するレイアウトの追加がある。スマートフォンでは盤の左右を占めずに済む配置として参考にした。将棋ウォーズの公式対局画面案内は盤面・駒・双方の情報欄を案内するが、持ち駒欄の細かな配置は公開説明からは判別できなかった。

- [将棋ログ（App Store）の更新履歴](https://apps.apple.com/us/app/shogi-log/id6737223881)
- [将棋ウォーズ公式Q&A](https://shogiwars-cdn.heroz.jp/qa)

## 本人との設計確認と合意

- 成功条件は、`render_position` が表示する初期局面・着手後・読込後の局面すべてで、先手・後手双方の持ち駒を確認できること。
- 盤の上に後手、下に先手の持ち駒欄を置き、手番・対局形式によらず双方を表示する。
- 0枚は「なし」。所持駒は歩・香・桂・銀・金・角・飛の順に列挙し、1枚も枚数を明記する。
- 表示責務は既存の `render_position(position) -> str` に置く。公開シグネチャ、モデル、CLI進行処理を変えない。
- 全文比較テストの目的を維持し、双方の側、固定順、枚数、0枚、局面非変更をテストする。
- `unittest`、CLIでの手動対局、`git diff --check` で確認する。
- 設計仕様と実装計画のそれぞれを読み、本人が明示的に承認してから次段階へ進む。
- 学習記録・知識メモに加えて表示規則の参照メモを `docs/knowledge/` に残す。
