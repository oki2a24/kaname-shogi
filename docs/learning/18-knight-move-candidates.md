# 第18回：桂馬の移動先候補

## 目的

桂馬（`KNIGHT`：桂馬を表す駒種のデータ）が、先後に応じて前方へ2段、左右へ1筋の位置へ移動することを理解する。途中のマスを飛び越せること、到着先だけを候補として判定することも確認する。今回の学習では、成桂の動き、成り・不成、行き所のない桂の合法性、実際の移動、駒取り、持ち駒、王手、合法手判定、手番による合法手の確定は扱わない。

## 要点

- 桂馬は自分から見た前へ2段、左右へ1筋の位置に進む。
- 先手は段を2つ減らし、後手は段を2つ増やす。
- 途中のマスは経路として調べず、駒を飛び越せる。
- 到着先が盤外なら候補に含めない。
- 到着先が自駒なら候補に含めない。
- 到着先が空マスまたは相手駒なら候補に含める。
- 候補生成は盤面を変更せず、実際の移動や駒取りではない。
- 角・飛車のような方向ごとの走査駒とは異なり、到着先2マスを直接計算する。

## 確認問題と回答

### 第1問：先手の桂馬

本人の回答：

「6三4三。到着先の途中に駒が置かれていても移動できる理由は、桂馬は他の駒を飛び越せる駒だから」

評価・補足：正解。先手５五からは６三・４三が候補であり、桂馬は途中のマスを経路として通過しないため、途中の駒を飛び越せる。

### 第2問：後手の桂馬

本人の回答：

「6七4七。先手とは段の向きが逆になる。」

評価・補足：正解。後手は段の大きい方向へ前進するため、５五から６七・４七が候補になる。先後で前方の段方向が反転する。

### 第3問：自駒と相手駒

本人の回答：

「6三は候補ではない、自分の駒があるため。43は候補、相手の駒のマスには移動できるため」

評価・補足：正解。６三の自駒は候補に含めず、４三の相手駒は候補に含める。ただし候補生成では相手駒を取り除かない。

### 第4問：盤外

本人の回答：

「候補は無し。すべて盤外」

評価・補足：正解。先手の桂馬が２二にある場合、前方へ2段進む先は段０となり、２候補とも盤外になる。

### 第5問：盤面の不変性

本人の回答：

「まだ駒を移動していないため」

評価・補足：正解。候補生成は到着先を調べる操作であり、実際の移動や駒取りではないため、桂馬や到着先の駒を盤面から変更しない。
