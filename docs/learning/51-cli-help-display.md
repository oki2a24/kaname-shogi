# 第51回：CLIの対局中help表示

## 目的

人間の手番で `help` を入力すると、利用できる5種類のコマンド書式と短い説明を表示し、局面・手番・棋譜を変えず同じ手番で入力を続けられるようにする。

設計仕様は[CLI help表示の設計仕様](../plans/2026-10-01-cli-help-display-design.md)、実装手順は[CLI help表示の実装計画](../plans/2026-10-01-cli-help-display.md)に記録した。

## 設計合意

- `HelpCommand` は引数なしの凍結データ型として、解析済みのhelp指示を表す。値の生成は表示や局面変更をしない。
- 公開 `Command` Union と `cli.__all__` に `HelpCommand` を加える。既存の公開名の順序は維持し、`LoadCommand` と `Command` の間に置く。
- `parse_command("help")` のみを受け付け、`help now` と `HELP` は既存の形式エラーにする。
- `run_game` は固定ヘルプ文字列を `output_fn` に一度渡し、入力案内を再表示して同じ人間手番のループを続ける。
- 既存の文法、エラー文言、将棋規則、保存形式、毎回の入力案内は変更しない。
- READMEのCLI操作に利用方法を追加する。実端末での手動確認と知識メモ追加は対象外。
