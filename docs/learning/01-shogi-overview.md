# 第1回：将棋の全体像

## 学習の目的

将棋プログラムを作るための出発点として、対局の目的、盤面の大きさ、手番、駒の種類を説明できるようにする。

## 授業の要点

- 対局の目的は、相手の玉将（玉）を相手より早く**詰ます**こと。詰ませた側が勝つ。[日本将棋連盟「対局規則」第1条](https://www.shogi.or.jp/match/taikyoku_rules/)
- 本将棋の盤は 9×9、合計81マスである。[日本将棋連盟「対局規則」第3条](https://www.shogi.or.jp/match/taikyoku_rules/)
- 最初に指す人を先手、次に指す人を後手と呼ぶ。[日本将棋連盟「将棋とは？」](https://www.shogi.or.jp/knowledge/about/)
- 対局開始時、各対局者は8種類・合計20枚の駒を持つ。駒の種類は、玉将（王将）、飛車、角行、金将、銀将、桂馬、香車、歩兵である。[日本将棋連盟「対局規則」第3条](https://www.shogi.or.jp/match/taikyoku_rules/)

## 確認問題と回答

1. 将棋の目的は何ですか。
   - 回答：つますこと。相手の玉がどのように動いても、自分が玉を取れる状態にすること。
2. 最初に指す側を何といいますか。
   - 回答：先手。
3. 将棋盤は何マスで、何×何ですか。
   - 回答：81マス。9×9。
4. 駒は何種類ありますか。名前を挙げてください。
   - 回答：王（玉）、飛、角、金、銀、香車、桂馬、歩。

## 振り返りと補足

評価：全問正解。

第1問の「詰み」は、玉が逃げられない状態だけを指すのではない。王手に対し、玉を逃がす・王手をかけている駒を取る・駒を間に置くなど、**次にどのように応対しても玉が取られることを防げない状態**が詰みである。[日本将棋連盟「対局規則」第1条](https://www.shogi.or.jp/match/taikyoku_rules/)
