## 理解確認と補足

### 深さの途中停止

質問：深さ2まで完了し深さ3の途中で上限による通常停止になった場合、手・評価・完了深さに何を使うか。

本人回答：`深さ2`

補足：深さ2の完了した手・評価・完了深さを使い、深さ3の途中結果は使わない。本人の短い回答と、アシスタントが補った各項目を区別する。

### 完了記録がない場合

質問：深さ1も完了していない段階の通常停止では、どの手を返すか。

本人回答：`予備種`

補足：「合法予備手」を指す回答と解釈した。最初に合法性を確認して確保した手を返し、架空の評価や完了深さを付けない。

### 上限期間と実応答時間

質問：設定した上限時間になっても、その瞬間に必ず手が返るとは限らないのはなぜか。

本人の初回回答：`評価からてを選ぶ必要があるため`

補足：主因は停止確認点まで処理が続くこと。単一の複製・利き計算・評価を強制切断せず、合法予備手確保または手なし確定までは通常停止を保留する。停止後に評価をやり直して手を選ぶ必要はない。

再確認：評価処理の途中で上限時間に達した場合、その瞬間に強制終了するか、次の停止確認点で止まるか。

本人回答：`次の停止地点で止まる`

補足：次の停止確認点で止まるという理解を確認した。上限期間は停止判断の基準であり、期限内の応答保証ではない。
