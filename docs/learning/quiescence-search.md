## Task 1：末端接続と上限未完了の反復境界

`QuiescenceLimit`を値・手なしの不変マーカーとして追加し、`ControlledSearchOperations`末尾の任意`search_leaf`へ終端確認後に委譲する。下限・上限・同一SearchControlをそのまま渡す。αβ・minimaxは通常中断と別のマーカーとして伝播する。反復深化は未完了深さを採用せず、前回完了手または初回の合法予備手を維持する。追加した`on_iteration`観測は開始した反復の結果だけを一度受け取り、開始前停止では呼ばず、例外を伝播する。

新しい手作り木では基準がB `(0, 2)`、末端拡張がA `(0, 4)`。終端Bへ末端操作を呼ばない。独立レビューで初回は「深さ2の先頭枝が未完了」「前回完了手と予備手が同じ」という検出力不足が指摘された。木を予備手A・深さ1完了手B `(0, 5)`へ変え、深さ2ではB枝を採点してからA枝だけを未完了にし、αβ・全幅両方でQUIESCENCE_LIMIT、完了深さ1、評価、手B、観測順を検証した。レビューで指摘された上限の受渡しも、最小化中に`upper == (0, 2)`となるケースを追加して確認した。

TDDで、未接続の末端操作による手選択が期待どおり変わらないassertion failure、未完了型・終了状態がないassertion failure、反復が未完了markerを`move`として扱う不具合を確認した。誤実装を隔離コピーへ入れる検出確認では、上限未完了をCOMPLETEと誤報する変異と、末端へ上限を渡さずNoneにする変異がそれぞれ意図したassertion failureになった。復元後は成功。

## Task 2：将棋の静止探索と計数

`tests/test_search_shogi.py`のKINGS・MATE・RECAPTUREを読み、合法手生成を使った小局面を作成した。RECAPTUREの既存局所値（開始13、`5e5d`後15、`5c5d`後−15、`4e5d`後3）を使い、対象手順と静的評価を手計算値で照合した。製品の駒価値と論文紹介用の角8・飛車10を混同しない。

`quiescence.search`は王手なしではstand patを基準に合法な捕獲のみを調べ、王手中は捕獲・玉移動・合駒を含む合法な回避を調べる。追加手数上限は各遷移で減らす。上限到達が王手なしなら静的評価、王手中で非詰みなら`QuiescenceLimit`、詰みなら詰みスコアを返す。候補探索はαβ境界を使う。`make_quiescence_operations`は通常探索の末端と静止探索を接続し、`SearchCounters`は通常調査回数と静止探索呼出し回数を任意に記録する。根の準備・合法手生成内部の再帰は調査計数に含めない。
