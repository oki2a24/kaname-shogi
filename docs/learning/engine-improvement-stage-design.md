## 方針選択の経緯

1. 二手で止めた後の取り返しを起点に学ぶことを選択。
2. 本人から、深く読む方向だけでなく、他の方向と選定理由を検討したいとの指摘。比較基準を先に整理し、全幅読み、駒取り継続、局面評価、定跡を比較した。
3. 局面例での確認を先に行い、棋力測定は後段とすること、枝ごとの駒得差を追うことを選択。
4. 静かな逃げも含めて検討。全幅四手と駒取り継続を比べ、次に局面評価を学ぶ順を選択。
5. 本人の質問から、定跡を別軸の候補として追加。未知局面の判断を主目的に選択したため、今回の中心にはしない。

## 本人との合意

- 比較対象：枝刈りなしのミニマックスとαβ枝刈り付きミニマックス。二・三・四手を独立実行する。
- 現行の駒得評価と詰み優先を使用。勝ち同士・負け同士は同点、詰み距離は比較しない。詰みでない手なしは駒得評価。
- 根の評価値の一致と、選択手が最善評価の候補に含まれることを成功条件とする。選択手の完全一致を別の成功条件にはしない。
- 訪問回数は開始・途中・末端を含み、再訪も数える。両方式の探索順をそろえる。同点は探索順で最初の最善手を選ぶ。
- 開発用比較まで。SFEN入力で二・三・四手の評価値・選択手・訪問回数を表示。手はUSI表記と日本語説明を併記する。
- 指定深さまで完了して比較。時間制御・反復深化は今回対象外。手動中断は未完了で成功に数えない。
- Random（最弱・既定）、一手駒得、現行二手先読みを維持。二手先読みを初期の維持一覧から漏らしたアシスタントの説明を、本人の指摘で訂正した。
- 新しい探索と必要な共通処理をファイル分割。既存三方式の全面分割は今回対象外。
- 取り返し、静かな逃げ、枝刈りあり／なし、同点、詰みの性質を確認。SFEN局面に加え、数値だけの小さな探索木も併用することに本人が同意。
