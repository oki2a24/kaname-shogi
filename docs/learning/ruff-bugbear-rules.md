## 要点

Bはflake8-bugbear由来のルール群である。今回の固定版Ruff 0.16.10ではBの39ルールが有効となり、基本ルール59と合わせて98ルールになった。previewは有効にしていない。Bのすべてをこの回で詳説したわけではなく、代表例としてB006とB008の意味と検出を確認した。

- **B006**：既定引数のリストなど、変更可能なデータが呼び出し間で共有される誤りを検査する。
- **B008**：既定引数に書いた関数呼び出しが、呼び出しごとではなく関数定義時に一度だけ実行されることによる誤りを検査する。すべての関数呼び出しが常に誤りという意味ではなく、公式に例外の説明もある。

以下は学習用の例であり、本体へ追加していない。

```python
def add_value(value, values=[]):
    values.append(value)
    return values
```

`add_value` は値を追加する**操作**、`value` は追加する値の**データ**、`values` はリストという**データ**、`append` はリストへ値を末尾追加する**操作**である。

既定引数の `[]` は関数定義時に作られるため、引数を省略した呼び出しで同じリストが使われる。`add_value(1)` の後に `add_value(2)` を実行すると、後者は `[1, 2]` を返す。毎回新しいリストを使う意図なら次のようにする。

```python
def add_value(value, values=None):
    if values is None:
        values = []
    values.append(value)
    return values
```

出典：[B006](https://docs.astral.sh/ruff/rules/mutable-argument-default/)、[B008](https://docs.astral.sh/ruff/rules/function-call-in-default-argument/)、[段階的なルール選択](https://docs.astral.sh/ruff/linter/#rule-selection)。
