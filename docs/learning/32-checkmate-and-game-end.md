# 第32回：詰み・終局判定

実施日：2026-09-23

## 目的

詰みを「王手を受け、現在実装済みの規則で王手を防ぐ合法手が一つもない状態」として判定し、詰みだけを扱う最小の終局判定を追加する。試行中も元の局面を変更しないことを確認する。

## ルールの確認

日本将棋連盟は、詰みを「次にどのように応対しても玉が取られてしまうことを防げない状態」と定め、詰みで対局が終了すると定めている。王手は玉を逃がす、王手駒を取る、飛車・角・香の直線王手なら合い駒を置くことで防げる。桂馬の王手は合い駒では防げない。打ち歩詰めも反則だが、今回は次テーマへ分離した。

出典：[日本将棋連盟「対局規則」](https://www.shogi.or.jp/match/taikyoku_rules/)、[日本将棋連盟「王手と詰み」](https://www.shogi.or.jp/knowledge/shogi/04.php)、[日本将棋連盟「反則について」](https://www.shogi.or.jp/knowledge/shogi/05.php)

## 確認問題

### 第1問

問題：「手番側に合法手が一つもない」だけでは詰みといえません。詰みと判定するために、もう一つ必要な条件は何でしょうか。

本人の回答：次にどの様に応対しても玉が取られることを防げないこと

補足：正解。プログラムでは、手番側が王手を受けていることと、王手を防ぐ合法手が一つもないことを両方確認する。

### 第2問

問題：王手を防ぐ合法手には、玉を逃がす以外にどのような方法がありますか。

本人の回答：合駒、玉と玉を取る相手駒の間に自分の持ち駒、を置く

補足：合駒は正解。飛車・角・香の直線王手なら、盤上の自駒を動かすか持ち駒を打って間を遮れる。さらに、王手駒を安全に取る方法もある。桂馬の王手は合い駒では防げない。

### 第3問

問題：王手を受けていない局面で、手番側に合法手が一つもない場合、第32回の最小実装ではどの扱いにするのがよいと思いますか。

本人の回答：続行。王手を受けていないので詰みではないため

補足：正解。詰みは防ぎようのない王手であるため、王手でない局面は終局にしない。

### 第4問

問題：候補生成用の玉がない部分局面を、詰み判定でどう扱うのがよいでしょうか。

本人の回答：「詰みではない（`False`）」として扱う方針でよい

補足：正解。既存の `is_in_check` と同じく、不完全な部分局面を例外や詰みとは扱わない。

### 第5問

問題：詰み判定で、全候補を複製局面で試す方法で進めてよいでしょうか。

本人の回答：「全候補を複製局面で試す」方法で進めてよい

補足：合意した。既存の適用操作へ規則を委譲し、玉の退避・王手駒の取得・盤上と持ち駒の合い駒を同じ手順で確かめる。

## 設計の合意

`has_legal_move(position)`、`is_checkmate(position)`、`is_game_over(position)` を公開する。合法手の有無は、手番側の全盤上駒の候補に対する不成・成りと、玉以外の全持ち駒の全打ち先を、局面の複製に適用して調べる。詰みは王手かつ合法手なし、終局は今回に限り詰みだけとする。玉がない部分局面は偽とする。打ち歩詰め、投了、千日手、持将棋、入玉、反則勝敗、CLI入力は対象外とした。

設計仕様は [詰み・終局判定：設計仕様](../plans/2026-09-23-checkmate-and-game-end-design.md)、実施手順は [詰み・終局判定 実装計画](../plans/2026-09-23-checkmate-and-game-end.md) を参照する。
