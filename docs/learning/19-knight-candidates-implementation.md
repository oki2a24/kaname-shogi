## 実装後の理解確認

### 第1問：相手駒と盤面不変性

本人の回答：

「相手駒のあるマスは移動できるから。候補生成後は盤面は候補生成前と同じ状態になっている必要がある。」

評価・補足：正解。相手駒のある到着先は、実際の指し手では相手駒を取れるため候補に含める。ただし候補生成は実際の移動や駒取りではないため、処理後の盤面は処理前と同じ状態でなければならない。
