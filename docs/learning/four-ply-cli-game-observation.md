# CLIでαβ枝刈り最大4手を選び、数手の対局を観察する

## 学習の目的・範囲

2026-10-19、CLI対局で新しい一手選択方式を一つ選び、コンピュータの応答を数手観察した。目的は、方式選択・人間入力・コンピュータ手・局面表示・投了の流れを実際のCLIで確かめ、画面から分かることと分からないことを区別すること。

対象は学習と手動観察。製品コード、テスト、設定、実装計画は変更しない。結果はこの一回・初期局面・この端末の観察に限る。実時間保証、深さ4到達、全局面の正しさ、棋力向上へ一般化しない。

対局後の再確認では `main` のHEAD `0d81528` が `origin/main` と一致し、未追跡 `.antigravity/tasks/` だけが残っていた。追跡ファイルの変更はなかった。最初の表示から追跡先が変化した理由は調査していない。

CLIの既存3方式はランダム、一手駒得、二手先読み（駒得）。新しい方式は全幅読みとαβ枝刈りで、どちらも各コンピュータ手で深さ1から最大4まで反復する。全幅読みは枝を省かず、αβ枝刈りは最善手の決定に影響しない枝を省く。CLIに時計による探索時間制御はない。前テーマの接続実装ではメニュー・選択アダプター等をテストしたが、新方式を選ぶCLI実プロセス対局は未確認だった。

`kaname_shogi/__main__.py`、`kaname_shogi/cli.py`、`kaname_shogi/game_search.py`を確認し、起動・方式選択・人間の指し手入力・コンピュータ手の表示・`resign`による投了終了の流れを読んだ。

## 観察した一局

リポジトリルートで次を起動した。

```sh
python3 -m kaname_shogi
```

CLIで `2`（人間対コンピュータ）、`5`（αβ枝刈り（最大4手））を選んだ。初期局面で先手が次の手を入力した。

1. 先手 `move 7 7 7 6`（7七歩→7六歩）。後手の表示手は `move 3 3 3 4`（3三歩→3四歩）。局面が再表示され、先手の入力プロンプトへ戻った。
2. 先手 `move 7 6 7 5`（7六歩→7五歩）。後手の表示手は `move 2 2 8 8 +`（2二角→8八角成）。局面が再表示され、後手の持ち駒に「角1」と表示された後、先手の入力プロンプトへ戻った。

二回目の応答後に `resign` を入力した。CLIは「先手が投了しました。後手の勝ちです。」と表示し、プロセス終了コードは0だった。

各応答にかかった時間は、端末出力に計測値がなく、待機呼び出しの合計からの概算でいずれも約5分（初回は約5分10秒、二回目は約5分）だった。これは今回の初期局面からの二回に限った観察値であり、専用の時間計測ではない。

## 今回の表示から分かること・分からないこと

- CLIで5番を選び、人間の二手に対してコンピュータの応答が二回表示され、局面・持ち駒も更新された。投了で対局が終了した。
- 探索中の進捗や深さ、時計は表示されなかった。したがって、各応答が深さ4まで完了したかは画面から確認できない。
- AlphaBeta4でも今回の応答には約5分かかった。全幅読みは枝を省略しないため、より多くの探索になる可能性はあるが、全幅読みをこのCLI・局面で実行していないので、その待ち時間は未確認である。
- この観察だけでは、時間保証、他の局面での正しさ、全ての合法手の扱い、深さ4到達、棋力向上を示せない。

## 最後の理解確認（2026-10-19）

**質問:** 今回の観察だけから、何が言えて何が言えませんか？ 応答表示を深さ4到達や、全局面の正しさ・棋力向上の証明とできるか、その理由も教えてください。

**本人の回答:**

> １手打つのに時間がかかっていると感じる枝刈りでこれなので、全幅ではもっと時間がかかりそう。深さ４到達、正しさ、棋力向上の証明は、途中経過が一切見えないのでできない

**アシスタントの補足:** 応答が出るまで長く待ったこと、CLIに探索途中の表示がなかったことから、今回の局面・実行条件での経験と、深さ4や正しさを証明できない点を分けて説明できている。全幅読みは枝を省略せずαβ枝刈りは不要な枝を省くため、全幅の計算量が増える可能性はある。ただし今回全幅を実行しておらず、全幅の実際の待ち時間やこの局面での差を確認したわけではない。

## 振り返り・次回への問い

CLIメニューから方式を選び、実際の人間対コンピュータ対局で二回の応答と投了を観察できた。一方、応答表示までの待ち時間が長く、探索中に進捗や完了深さが見えないため、画面だけで深さ4完了を確かめられなかった。待ち時間から全幅読みの具体的な所要時間を予測したり、棋力を評価したりはしない。
