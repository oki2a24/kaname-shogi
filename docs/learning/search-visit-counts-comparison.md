# 小さい局面で全幅とαβの訪問回数を比べる

## 目的・範囲

全幅読みは枝を省かずに調べ、αβ枝刈りは評価に影響しないと判断した枝を省く。訪問回数は共通探索本体への訪問数で、合法手生成・王手確認内部の確認局面は含まない。訪問回数を実行時間や総作業量と同一視しない。
