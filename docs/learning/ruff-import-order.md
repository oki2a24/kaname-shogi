## 要点

Iはisort由来のルール群で、importのグループ分け、並び順、重複整理を確認する。今回の固定版で選択されるのはI001とI002。I002の必須import指定は追加せず、今回の21件はすべてI001だった。B追加後の98ルールから合計100ルールになった。

`import` はモジュールを読み込む**操作**。`Path` はファイルやディレクトリのパスを表す**データの型**である。例えば次の並びを、標準ライブラリの通常のimportとfrom形式のimportの順に整理する。

```python
# 整理前
from pathlib import Path
import sys

# 整理後
import sys
from pathlib import Path
```

同じグループ内の順序に加え、標準ライブラリ・外部パッケージ・プロジェクト内のimportを区別して整理する。独自の並び順設定は追加していない。フォーマッタ単独ではimport順序を整理しないので、次の順で操作する。

```sh
.venv/bin/ruff check --select I --fix .
.venv/bin/ruff format .
.venv/bin/ruff check .
```

import順序はモジュール初期化の順序にも関わるため、自動修正後も差分確認とテストを行う。フックは自動修正せず、ステージした内容の違反でコミットを止める。

出典：[I001公式資料](https://docs.astral.sh/ruff/rules/unsorted-imports/)、[import整理とフォーマッタ](https://docs.astral.sh/ruff/formatter/#sorting-imports)、[自動修正と整形の順序](https://docs.astral.sh/ruff/integrations/#pre-commit)。
