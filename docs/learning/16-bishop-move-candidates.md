# 第16回：角の移動先候補

## 目的

飛車の複数方向の走査を土台に、角が斜め4方向へ進めることと、方向ごとに駒で停止することを理解する。今回の学習では、成り、馬の動き、実際の移動、駒取り、持ち駒、王手、合法手判定は扱わない。

## 要点

- 角（`BISHOP`：角行を表す駒種のデータ）は、斜め4方向へ任意のマス数進める。
- 空いているマスは候補に含める。
- 自駒のマスは候補に含めず、その方向の手前で止める。
- 相手駒のマスは候補に含めるが、その先へは進まない。
- 角の4方向は互いに独立して調べる。
- 飛車と共通するのは、方向ごとに1マスずつ走査し、盤外または駒で止める点である。相違点は、飛車が縦横、角が斜めを進む点である。

## 確認問題と回答

### 第1問

５五の角が盤上に他の駒がないときの候補を、次のように回答した。

本人の回答：

「4四3三2二1一、6四7三8二9一、4六3七2八1九、6六7七8八9九」

評価・補足：正解。斜め4方向を、各方向で出発マスに近い順に列挙できている。角は筋と段を同時に1つずつ変えて進む。飛車のように筋だけ、または段だけを変える駒ではない。
