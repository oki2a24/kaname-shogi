# 第36回：棋譜・局面の保存

実施開始日：2026-09-23
設計承認日：2026-09-23

## 目的

CLIで成功した盤上移動・駒打ちの順序をメモリ上へ保存し、開始局面から任意の手数の局面を再現できるようにする。保存対象、保存時機、再現範囲、CLIとの関係、SFEN/USIの扱いを一問ずつ確認し、設計承認後にTDDで実装した。

## 一次資料で確認した規則

日本将棋連盟の対局規則第12条第1項は、公式棋戦で記録係または自動記録による採譜を行うと定める。第12条第2項は、棋譜と時間を正確に記録することを記録係の役割としている。棋譜利用のガイドラインは、公式記録に基づき指し手進行を再現した盤面図と、指し手順の文字情報を棋譜と説明する。

今回は時間管理を実装していないため、採譜のうち成功した指し手の順序と局面再現だけを対象にした。

出典：[日本将棋連盟「対局規則」](https://www.shogi.or.jp/match/taikyoku_rules/)、[日本将棋連盟「棋譜利用のガイドライン」](https://www.shogi.or.jp/kifuguideline/)

## 確認問題と回答

### 第1問：保存対象

問題：今回、最初に保存する対象をどこまでにするか。

提示した推薦：メモリ上の「初期局面からの指し手履歴」と「現在局面の独立した複製」まで。ファイル保存は扱わない。

本人の回答：1とする。ファイル保存は次回？

補足：ファイル保存・読み込みは今回の対象外とし、この保存モデルが安定した次回テーマの候補とした。

合意：開始局面からの成功手の履歴と現在局面の独立複製をメモリ上で保持する。

### 第2問：保存時機

問題：履歴と現在局面を更新する時機をどうするか。

提示した推薦：`move` または `drop` が合法として成功した直後だけ更新し、形式・合法性エラーでは何も保存しない。

本人の回答：1とする。

合意：既存の合法手適用が成功した後だけ履歴と現在局面を更新する。

### 第3問：再現範囲

問題：履歴からどこまで再現できるようにするか。

提示した推薦：開始局面から履歴の任意の手数まで順に適用し、その時点の局面を再現する。現在局面の複製も併せて持つ。

本人の回答：1とする。

合意：`position_at` で0手目から最終手までの任意手数を再現する。各手後の局面を全件保存しない。

### 第4問：CLIとの関係

問題：CLIと保存記録をどう結び付けるか。

提示した推薦：`run_game` が対局記録を作り、合法な `move` / `drop` を記録経由で適用し、終了時に記録を返す。CLI画面に保存コマンドは追加しない。

本人の回答：1とする。

合意：`run_game` は詰み・投了・EOF・Ctrl-Cのいずれでも、その時点の `GameRecord` を返す。投了などの入力イベントは指し手履歴に含めない。

### 第5問：SFEN・USI

問題：SFENとUSIを今回どう扱うか。

提示した推薦：どちらも実装せず、既存の `Square`、基本駒種、成り指定を使うPython内部の値で履歴を表す。

本人の回答：1とする。

合意：SFEN、USI、ファイル保存・読み込みは次テーマ以降へ分離する。

## 設計合意と実装

設計仕様：[第36回設計仕様](../plans/2026-09-23-game-record-and-position-save-design.md)

実装計画：[第36回実装計画](../plans/2026-09-23-game-record-and-position-save.md)

`GameRecord` は開始局面、現在局面、成功した指し手列を持つ対局記録である。`RecordedMove` は盤上移動の不変データ、`RecordedDrop` は駒打ちの不変データである。局面の合法性は既存の `apply_move` / `apply_drop` に委譲し、成功後だけ履歴へ追加する。開始局面・現在局面の公開値は複製を返し、`position_at` は開始局面から指定手数を再適用する。

CLIは `GameRecord` を作成して指し手を記録経由で適用し、終了時に記録を返す。`resign`、EOF、Ctrl-Cは履歴へ追加しない。SFEN、USI、ファイル保存は実装していない。

## 最後の理解確認

main取り込みと取り込み先検証まで完了したため、次の一問を出し、本人の回答を待つ。

問題：なぜ現在局面だけを保存するのではなく、開始局面と成功手の履歴から任意手数の局面を再現できるようにしたのか。

本人の回答：棋譜として再現できる様にするため

補足：その通り。棋譜は指し手順から対局の進行と各時点の盤面を再現するものなので、現在局面だけでは途中の経過を振り返れない。開始局面と成功した指し手の履歴を保存し、指定手数まで再適用することで、対局の途中と最終局面を同じ規則で再現できるようにした。
