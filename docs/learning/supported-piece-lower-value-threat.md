## 最後の理解確認（2026-10-31）

質問：MとUが同じ二つの指し手で、片方はV=0、もう片方はV=-1になるとき、評価器はどちらを選ぶか。Vの符号が表すことも説明する。

本人回答：「V=0。Vは味方の支えがあり、より安い相手駒に狙われた非玉駒を一枚につき1と数え、相手引く自分」

補足：差は「相手側の対象枚数−自分側の対象枚数」。V=0は両側の対象枚数が同じで、V=-1は自分側に対象が一枚多いことを表す。MとUが同じなら `10M+U+V` は0の枝を−1の枝より高く評価する。これはVの定義と合成式の理解確認であり、棋力向上を示すものではない。
