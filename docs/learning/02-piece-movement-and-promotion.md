# 第2回：駒の動きと成り

## 学習の目的

8種類の駒の基本的な動き、飛び越えの可否、成りによる変化を説明し、将棋プログラムで駒の移動候補を実装するための土台を作る。

## 授業の要点

- 「前」は自分から見て相手側へ進む方向である。先手と後手では盤上の向きは反転するが、各駒の規則は自分から見た前後で共通である。
- 玉は周囲の8方向へ1マス、飛は縦横へ任意のマス数、角は斜めへ任意のマス数動く。
- 金は前・後ろ・左右・斜め前へ1マス動き、斜め後ろには動けない。銀は前・斜め前・斜め後ろへ1マス動き、横と真後ろには動けない。
- 桂は前へ2・横へ1の位置へ進み、途中の駒を飛び越えられる。香は前へ任意のマス数、歩は前へ1マス動く。
- 飛・角・香は途中の駒を飛び越えられない。桂だけが飛び越えられる。
- 玉と金は成れない。飛は竜、角は馬になり、それぞれの基本の動きに1マスの動きが追加される。銀・桂・香・歩は成ると金と同じ動きになる。

駒の移動規則と成り後の動きは、日本将棋連盟の[「駒の動きと特徴」](https://www.shogi.or.jp/knowledge/shogi/03.php)および[「対局規則」第4条](https://www.shogi.or.jp/match/taikyoku_rules/)で確認した。成りは、移動前または移動後に敵陣に入ると選べ、成った駒は元に戻らない。[「対局規則」第5条](https://www.shogi.or.jp/match/taikyoku_rules/)

## 確認問題と回答

1. 何マスでも進める駒を3種類挙げ、それぞれの進む方向を答えてください。
   - 回答：飛車は縦横、角は斜め、香車は前。
   - 評価：正解。
2. 他の駒を飛び越えられる駒は何ですか。
   - 回答：桂馬。
   - 評価：正解。
3. 金と銀の動きの違いを答えてください。
   - 最初の回答：金は左右と斜め後ろが不可、銀は後ろと左右が不可。
   - 補足：金は左右に動ける。金が動けないのは斜め後ろ、銀が動けないのは横と真後ろである。
   - 最終回答：金は後ろ斜め、銀は横と後ろ。
   - 評価：正解。
4. 成れない駒を2種類答えてください。
   - 回答：王（玉）、金。
   - 評価：正解。
5. 飛と角が成った後の名前と、追加される動きを答えてください。
   - 回答：飛車は竜になり斜めへ1マス、角は馬になり縦横へ1マス動けるようになる。
   - 評価：正解。

## 振り返り

全問正解。金と銀の違いは混同しやすいため、「金は後ろ斜めだけ苦手」「銀は横と真後ろが苦手」と対比して覚える。

資料を見ながら確認することは、実装時にルールを一次情報へ戻って検証する習慣につながる。今回は、確認後に自分の言葉で正しい規則を答えられた。
