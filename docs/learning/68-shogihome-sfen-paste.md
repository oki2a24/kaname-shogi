# 第68回：ShogiHome画面へのSFEN貼り付け確認

## 状態

2026-10-07、ShogiHome 1.28.1の画面で4欄SFENと手数欄を省いた3欄SFENを貼り付け、期待した盤面・手番・持ち駒を確認した。本人の最終理解確認も完了した。画面確認の記録はレビュー前で、文書変更は未コミット。ShogiHomeから `kaname-shogi` へのUSI連携は未確認である。

## 目的

第67回で実装したSFEN読込・書出しとは分けて、ShogiHome画面がSFENの貼り付けを受け付け、指定した局面を表示するか確認する。手数欄あり・省略の両方を、同じ局面で比べる。

## 本人が決めた確認範囲

- 3手後の局面 `7g7f 3c3d 2g2f` を入力例にする。
- 初期局面は標準的な基準確認に向く一方、画面がすでに初期局面なら貼り付け結果を見分けにくいため、変化が見える3手後局面を選ぶ。
- 4欄SFENと、手数欄だけを省いた3欄SFENを両方貼り付ける。
- 盤面のほか、後手番と持ち駒なしを期待表示として確認する。
- 操作開始前に未保存変更または稼働中セッションがあれば停止する。保存済みの既存棋譜は置き換えてよいが、保存・削除はしない。
- 4欄の表示が期待と違えば、3欄の確認へ進まず停止する。
- 最後は3欄の局面を未保存のまま表示しておく。
- クリップボードの元の内容を復元する。
- ShogiHomeからエンジンへの接続・対局・USIログ、設定変更、棋譜の保存・削除、コード・テスト変更は範囲外。
- 具体的な操作案を提示し、本人が「良い」と承認した後に、その範囲で実機を操作した。

## 入力例と期待表示

4欄SFEN：

```text
lnsgkgsnl/1r5b1/pppppp1pp/6p2/9/2P4P1/PP1PPPP1P/1B5R1/LNSGKGSNL w - 4
```

3欄SFEN（手数欄 `4` を省略）：

```text
lnsgkgsnl/1r5b1/pppppp1pp/6p2/9/2P4P1/PP1PPPP1P/1B5R1/LNSGKGSNL w -
```

期待する局面は、先手の歩が７六と２六、後手の歩が３四にあり、後手番で両者の持ち駒が空であること。

## 実機確認

- 開始時のアプリはShogiHome Version 1.28.1。初期局面が表示され、事前の未保存棋譜はなく、監視欄はUSIエンジン0・CSAサーバー0で稼働セッションなしだった。
- ShogiHomeの「ファイル」から「貼り付け」を開き、4欄SFENを貼り付けて新規ファイルとして取り込んだ。盤面の歩、後手番、空の持ち駒が期待と一致した。
- 続けて3欄SFENを同じ操作で貼り付けて取り込んだ。最終画面でも同じ盤面・後手番・空の持ち駒を確認した。
- 画面の棋譜欄は「開始局面」。タイトルは「未保存: 新規棋譜」で、3欄の局面を表示したまま残した。保存・削除はしていない。
- 貼り付け欄を開いた直後、元のクリップボードにあった別の文字列が欄へ入ったため、SFENに差し替えてから取り込んだ。その文字列は棋譜として取り込んでいない。最終の3欄確認では貼り付け操作を通し、貼り付け機能が元のクリップボードを復元する仕様を利用した。
- 操作中も監視欄はUSIエンジン0・CSAサーバー0で、稼働セッションはなかった。

## 確認できたことと未確認事項

ShogiHome 1.28.1の画面は、今回の3手後局面について4欄SFENと手数欄を省いた3欄SFENの両方を受け付け、期待した盤面を表示した。これは手動の画面貼り付けと表示の確認である。

ShogiHomeがこのSFENを `kaname-shogi` へUSI `position sfen` として送ること、エンジンが応答すること、通信ログの内容は確認していない。別バージョンや他のSFEN局面での動作も確認していない。第67回の実装テスト結果を、今回の実機確認の代わりとは扱わない。

## 振り返り

画面への貼り付け成功から分かるのは、今回の入力をShogiHomeのGUIが解釈して表示できたことまでである。エンジンへ同じ局面が送られるかは別の確認が要る。既存の接続手順書と専用スキルには `position startpos moves ...` のみ対応という古い説明が残るため、エンジン連携を次に扱う場合は、実通信を確かめる範囲と合わせて更新要否を検討する。

## 最終理解確認

**質問（2026-10-07）:** 今回の画面確認で、3欄SFENについて確認できたことと、まだ確認できていないことの境界は何ですか？

**本人の回答:** 「ShogiHome に sfen を渡すことが確認できた。kaname-shogi から sfen を渡すことが確認できていない。」

**アシスタントの補足:** ShogiHome 1.28.1の画面へ3欄SFENを貼り付け、取り込んだ局面が期待どおりに表示されることを確認した。一方、ShogiHomeがUSI `position sfen` を `kaname-shogi` へ送ることや、エンジンがその局面に応答することは確認していない。
