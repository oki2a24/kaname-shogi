# 反復深化で留保したテスト2件を補強する

## 学習の目的

前テーマの独立レビューで留保した2件について、テストが守る契約、代表ケース、想定する誤り、対象テスト単独と全体テストの検出範囲を説明できるようにする。現行コードの製品不具合修正ではなく、将来の回帰を検出するための補強である。

## 背景と範囲

独立ストリームの前回手と単独αβ段階のValueError伝播は現行実装では正常だが、前回の対象テスト群ではそれぞれ異なる誤実装を見逃した。前回の誤り注入は単独テスト群だけであり、全体513件での検出可否は未確認だった。

今回の範囲は `tests/test_search_iterative_deepening.py` の独立ストリームテストと、`tests/test_search_compare_iterative.py` の入力・内部例外テストの補強。Random（最弱・既定）、一手駒得、現行二手先読みは維持する。停止と既存時間制御の接続は後続希望であり、今回開始しない。

## 確認問題と回答

### 1. 独立ストリームの前回手

確認問題：「二つのストリームで前回手の混在を見分けるには、それぞれの深さ1の最善手を同じにするのと異なるものにするのと、どちらがよいでしょうか？」

本人の回答：「それぞれの深さ1の最善手を異なるものにするのが良い」

アシスタントの補足：正しい。現状の二つの数値木はどちらも深さ1でAを選ぶため、片方の前回手をもう片方が誤って受け取っても値が同じで、混在が表れにくい。深さ1の最善手をA/Bに分け、交互取得時にストリーム・深さ・`preferred_move` を観察すれば、各ストリームが自分の前回手を渡したか確認できる。

### 2. 単独αβ段階の内部例外

確認問題：「テスト用の置き換え関数は、`preferred_move` が渡された呼び出しと渡されない呼び出しで、それぞれどう振る舞えば単独αβ段階の例外を確かめられるでしょうか？」

本人の回答：「反復中のαβ呼び出しで先に例外が起き無いようにする」

アシスタントの補足：意図は合っている。反復中の呼び出しには `preferred_move` キーワードが明示的に付くので、その場合は実αβへ委譲する。単独比較は同キーワードなしで呼ばれるので、その場合だけValueErrorを送出する。呼出し記録も確認すれば、単独深さ1へ到達したことと例外伝播を区別できる。

### 実際の変更と契約

- `test_records_are_immutable_and_streams_independent` の二つ目の根直下評価をA=(0, 0)、B=(0, 1)にし、深さ1の最善手が一つ目のAと二つ目のBに分かれるようにした。根オブジェクトの同一性からストリームを識別し、αβ呼出しの `(ストリーム, 深さ, preferred_move)` が `first/1/None`, `second/1/None`, `first/2/A`, `second/2/B` となる契約を確認する。二つ目の記録の手B、凍結記録、返却結果との同一性、累計 `(3, 8)` も維持・確認する。
- `test_input_and_internal_errors` のαβ置き換え関数は `preferred_move` キーワードがある反復内呼出しを実αβへ委譲し、キーワードのない単独呼出しで `ValueError("単独探索の内部故障")` を送出する。呼出し列 `(反復, 1)`, `(単独, 1)` と例外伝播を確認する。入力エラー、help、反復・全幅探索での内部ValueError伝播も保持する。
- 製品コード、Random（最弱・既定）、一手駒得、現行二手先読みは変更していない。停止と既存時間制御の接続は扱わない。
