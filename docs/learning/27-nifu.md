# 第27回：二歩

実施日：2026-09-22

## 目的

持ち駒の歩を打つとき、同じ筋に自分の未成の歩を二枚置けない二歩を理解し、駒打ちの操作に最小の制限として加える範囲を決める。

## ルールの確認

[日本将棋連盟「反則について」](https://www.shogi.or.jp/knowledge/shogi/05.php)は、同じ筋に歩があるとき、もう一枚の歩を打つことはできず、その状態を二歩と説明している。また、成った歩である「と」と同じ筋に歩を打つことは二歩ではないとしている。

持ち駒を原則として好きな所へ打てることと、占有マス・行き所のない所へ打てないことは、[日本将棋連盟「駒の動かし方」](https://www.shogi.or.jp/knowledge/shogi/02.php)を参照する。

### 第1問

先手の持ち駒に歩が1枚あり、盤上の５筋に先手の歩がすでに1枚あるとする。先手はその持ち歩を、空いている５五へ打てるか。

本人の回答：打てない。打ったら反則負け。

補足：正しい。同じ筋に自分の未成の歩がある状態で、さらに持ち歩を打つと二歩という反則になる。プログラムでは、その局面変更を始める前に打ちを拒否する。

### 第2問

先手の持ち駒に歩が1枚あり、５筋には先手のと金だけが置かれ、先手の未成の歩はないとする。このとき、空いている５五へ持ち歩を打てるか。

本人の回答：できる。と金と歩は同じ筋に共存できる。

補足：正しい。二歩の対象は未成の歩であり、と金は成った歩なので対象ではない。

### 第3問

先手の持ち駒に歩が1枚あり、５筋に先手の未成の歩があるため、先手が空いている５五へ歩を打とうとした。プログラムはこの打ちを拒否するとき、盤面・持ち駒・手番をどう扱うべきか。

本人の回答：盤面・持ち駒・手番、いずれも変更しない。

補足：正しい。二歩は打ちが成立しないため、盤面81マス、先後双方の持ち駒、手番を全て変更しない。

## 設計の合意

`apply_drop(position, piece_type, destination)` の公開インターフェースは変えず、`PAWN` を打つときだけ、打ち先と同じ筋に手番側の未成の歩があるかを調べる。該当すれば `ValueError` で拒否し、持ち駒の減算、盤面への配置、手番交代を行わない。

判定は、盤面を変更せず「指定側の未成の歩が指定筋にあるか」だけを返す非公開操作に分ける。歩以外の駒打ち、行き所のない駒、打ち歩詰め、王手・合法手は扱わない。現在は成り状態が未実装のため、`PieceType.PAWN` を未成の歩として判定する。将来、と金を表現したときに二歩判定から外す。

詳細は[二歩の設計](../design/15-nifu.md)を参照する。
