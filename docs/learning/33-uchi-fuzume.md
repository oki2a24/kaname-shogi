# 第33回：打ち歩詰め

実施開始日：2026-09-23

## 目的

持ち駒の歩を打って、相手玉へ解除不能な王手をかける「打ち歩詰め」を反則として拒否する最小実装を学ぶ。

## ルールの確認

日本将棋連盟の対局規則は、打ち歩詰めを「持ち駒の歩を打って解除不能な王手をかける行為」と定め、反則としている。反則を犯した対局者は即負けとなる。

出典：[日本将棋連盟「対局規則」第10条第1項三](https://www.shogi.or.jp/match/taikyoku_rules/)

## 確認問題

### 第1問

問題：持ち駒の歩を打っても、相手玉が王手を受けていなかったり、合法的に王手を解除できたりする場合は、打ち歩詰めでしょうか。理由も教えてください。

本人の回答：うち歩詰ではない、解除可能なため。

補足：正解。打ち歩詰めになるのは、持ち歩を打った結果が王手であり、かつ相手側に王手を解除する合法手が一つもない場合だけである。例えば、後手玉が５一、先手玉が９九の局面で、先手が持ち歩を５二へ打つと、歩は５一を利かせるので王手になる。しかし５二が先手の別の駒に守られていなければ、後手玉は５二の歩を取って王手を解除できる。よって、この手は打ち歩詰めではない。

### 第2問

問題：５二の歩が先手の別の駒に守られていて後手玉が取れなくなったとしても、後手玉に別の安全な逃げ場があれば打ち歩詰めでしょうか。

本人の回答：打ち歩詰めではない。安全な逃げ場があるため。

補足：正解。王手を解除する方法は、王手駒を取ることだけではない。玉が相手の利きに入らないマスへ逃げられるなら、歩を打った結果は「解除不能な王手」ではない。

### 第3問

問題：盤上にある歩を動かして相手玉を詰ませた場合も、今回追加する「打ち歩詰め」の反則として禁止すべきでしょうか。理由を教えてください。

本人の回答：禁止しない。打ち歩ではなく、元々盤上にある歩を使用しているため。

補足：正解。対局規則が反則とするのは「持ち駒の歩を打って解除不能な王手をかける行為」である。盤上の歩の移動による詰みは、この限定された反則の対象ではない。

### 第4問

問題：持ち駒の金・飛車・角など、歩以外の駒を打って相手玉を詰ませた場合も、今回の打ち歩詰めとして禁止すべきでしょうか。

本人の回答：禁止しない。打ち歩詰めでは歩を打った時だけに適用されるため。

補足：正解。今回の反則は持ち歩に限定する。歩以外の駒打ちによる詰みは、将棋の規則上も「打ち歩詰め」ではなく、今回追加する拒否条件には含めない。

### 第5問

問題：`apply_drop` が打ち歩詰めかを確かめるため `is_checkmate` を呼び、`is_checkmate` が合法手を探すため `has_legal_move` を呼び、`has_legal_move` が候補の駒打ちを試すため再び `apply_drop` を呼ぶと、何が起こりそうでしょうか。

本人の回答：無限ループが起こりそう。

補足：正解。そのまま同じ公開操作同士を呼び合わせると、再帰が終わらない経路を作り得る。打ち歩詰めの確認では、相手の応手を調べる専用の内部経路を設け、通常の `apply_drop` が同じ打ち歩詰め確認を再開しないようにして、循環を断つ設計が必要である。

### 第6問

問題：テストのために相手玉を置いていない「玉なし部分局面」で、持ち歩を打っても打ち歩詰めとして拒否すべきでしょうか。既存の `is_checkmate` の扱いも踏まえて考えてみてください。

本人の回答：拒否しない。`is_checkmate` では玉なしでは False を返すので、こちらでも同様にするべき。

補足：正解。玉がない部分局面は `is_checkmate` が `False` を返す既存契約を維持する。よって、持ち歩を打っても打ち歩詰めにはならず、ほかの既存規則に反しない限り受け入れる。

打ち歩詰め確認中の応手探索では無効にすることで、公開操作同士の再入を一段で止めた。

## 最後の理解確認

### 問題

持ち歩を打った試し局面で詰みを調べる際、なぜ応手探索へ渡す `check_uchi_fuzume=False` では、二歩・行き所のない駒・自玉が王手になる手まで無効にしてはいけないのでしょうか。

本人の回答：すでにチェック済みだから？全然自信ない。

補足：一部正解。`False` にするのは、打ち歩詰めの確認が再び呼ばれて循環することだけを防ぐためであり、二歩・行き所のない駒・自玉への王手放置は別の合法手規則である。これらまで無効にすると、本来は応手にならない手を合法手として数えてしまい、詰みを誤って「詰みではない」と判定する。したがって、打ち歩詰め確認だけを無効にし、その他の既存の合法性検査は有効なままにする。
