## 実際の変更と判断理由

1. descriptionへSFEN局面を追加し、本文に `startpos moves <1手以上>`、SFEN単独、SFEN＋1手以上を明記した。startpos単独の未対応と通常平手・KIF再開の運用範囲は維持した。
2. SFENを読めること、局面の合法性、ShogiHomeでの一局面の送受信成功を区別した。他版・全局面・SFEN付き履歴の実機互換性は保証しない。手数欄の保持を推定せず、現行SFEN知識へ誘導する。
3. 本人が承認した時計文言を追記した。10分＋30秒を既定値・推奨値にせず、0＋0の試行を手順にしない。時計引数を使わないエンジンの制約と、エンジン時間切れOFFとの違いを示した。
4. ログOFF保存と現在プロセスへの反映を分け、OFF反映前の起動を禁止した。未保存棋譜で再起動を保留した場合は、無断で保存・破棄・再起動せず復帰未完了を報告する。第69回の保留は過去の観察であり、現在状態と推定しない。
5. スキル保守・資料調査を実機操作の承認と扱わず、過去の画面・版・登録先・棋譜・セッションを現在状態へ流用しないことを明記した。

詳細手順は既存手順書へ委譲し、手順書の併修・補助スクリプト・UIメタデータ追加は行わなかった。
