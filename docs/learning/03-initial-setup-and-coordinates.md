# 第3回：初期配置と盤上の座標

## 学習の目的

本将棋の初期配置を説明し、盤上のマスを筋・段の組で表せるようにする。これは、盤面をプログラムで初期化し、指し手を表現するための基礎になる。

## 授業の要点

- 本将棋では先手・後手が各20枚、合計40枚の駒を使う。
- 先手から見て、筋は左から `9`、`8`、…、`1`、段は上から `一`、`二`、…、`九` である。
- マスは筋と段の組で表す。`７六` は筋が7、段が六であり、「ななろく」と読む。
- 先手の一段目は、`９九` から `１九` に向かって香・桂・銀・金・王・金・銀・桂・香と並ぶ。先手の角は `８八`、飛車は `２八` に置く。
- 後手の一段目は、`９一` から `１一` に向かって香・桂・銀・金・玉・金・銀・桂・香と並ぶ。後手の飛車は `８二`、角は `２二` に置く。
- 両者の歩は、先手が七段、後手が三段の全9マスに置く。

初期配置、筋・段による符号、読み方は日本将棋連盟の[「駒の並べ方」](https://www.shogi.or.jp/knowledge/shogi/01.php)で確認した。将棋盤が9×9＝81マスであること、各側が8種類・合計20枚の駒を持つことは[「対局規則」第3条](https://www.shogi.or.jp/match/taikyoku_rules/)に基づく。

## 確認問題と回答

1. 先手の一段目に、`９九` から `１九` まで並ぶ駒を順に答えてください。
   - 回答：香・桂・銀・金・玉・金・銀・桂・香。
   - 評価：正解。
2. 先手の飛車と角は、それぞれどのマスにありますか。
   - 回答：飛車は `２八`、角は `８八`。
   - 評価：正解。
3. 後手の飛車と角は、それぞれどのマスにありますか。
   - 回答：飛車は `８二`、角は `２二`。
   - 評価：正解。
4. `７六` は、筋と段のどちらがどの数字ですか。
   - 回答：筋が7、段が六。
   - 評価：正解。
5. プログラムで盤上の位置を表すなら、1〜9のどの2つの値を持てばよいですか。
   - 回答：筋の1〜9と、段の一〜九の値。
   - 評価：正解。筋と段の組が位置を一意に決める。

## 振り返り

全問正解。

`９九` が先手から見た左下、`１一` が右上であることを、数学の座標の左下原点に対応付けるとイメージしやすい。たとえば内部座標を左下原点・0始まりにするなら、将棋の筋・段から `x = 9 - 筋`、`y = 9 - 段` と変換できる。これは実装上の選択であり、筋・段そのものをそのまま保持してもよい。
