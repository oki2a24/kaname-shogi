# 第14回：飛車の移動先候補

## 目的

香の一方向の走査を土台に、飛車が縦横4方向へ進めることと、方向ごとに駒で停止することを理解する。今回の学習では、成り、王手、合法手、実際の移動や駒取りは扱わない。

## 要点

- 飛車（`ROOK`：飛車を表す駒種のデータ）は、縦横に任意のマス数進める。
- 空いているマスは候補に含める。
- 自駒のマスは候補に含めず、その手前で止める。
- 相手駒のマスは候補に含めるが、その先へは進まない。
- 右方向が塞がっても、左・上・下方向は独立して調べる。

出典：[日本将棋連盟「駒の動きと特徴」](https://www.shogi.or.jp/knowledge/shogi/03.php)、[「駒の動かし方」](https://www.shogi.or.jp/knowledge/shogi/02.php)

## 確認問題と回答

### 第1問：５五の飛車が空いている盤で進めるマス

本人の回答：

「6五、7五、8五、9五、4五、3五、2五、1五、5四、5三、5二、5一、5六、5七、5八、5九。」

評価・補足：正解。横8マスと縦8マスの合計16マスである。候補順は設計時に決める。

### 第2問：自駒と相手駒がある場合

本人の回答：

「6五、7五、4五、3五、2五、1五、5四、5六、5七、5八、5九。」

評価・補足：列挙は正解。７五の相手駒は候補に含め、５三の自駒は含めない。自駒の先の５二・５一と、７五の先の８五・９五も飛び越せないため含めない。

### 第3問：自駒と相手駒の扱い

本人の回答：

「五手の銀のマスに置くことで銀を取ることができるから。先手の歩は自分の駒で、自分の駒は一つのますに複数置けないから」

評価・補足：正解。「五手」は７五の意味として解釈した。相手駒のマスは取る候補として含め、自駒のマスには進めない。

### 第4問：一方向が塞がった場合

本人の回答：

「調べられる。左や上下には他のコマはないため」

評価・補足：正解。飛車の4方向は独立しており、右方向の停止は他方向の走査を妨げない。

## 振り返り

本人の振り返り：「特にありません」
