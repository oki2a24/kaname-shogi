### 承認済みの入口と責務

- 専用モジュール `kaname_shogi.search.run_controlled_iterative`、`main(argv=None)`（解析・探索・表示を行い終了コードを返す操作）を提案し、全体承認に含めた。まだ製品ファイルは存在しない。
- 必須引数は `--sfen`、`--max-depth`、`--target-ms`、`--maximum-ms`。上限深さは1以上の整数、予算は整数msで `0 ≤ 目標 ≤ 上限`、既定値なし。argparseの標準動作を使い、独自の表記規則・重複拒否等を追加しない。
- 既存比較入口へモードを足す案より専用コマンドを選択。時間制御付き反復を一回だけ行い、比較探索は行わない。比較探索時間と探索予算を混同せず、観察に集中できるため。
- 持ち時間・秒読みから予算を計算する案より、目標・上限の直接指定を選択。SearchBudget（期間データ）を作り、既存のcalculate_search_budgetや設定読込は呼ばない。予算式を変更しない。
- 入力検査・予算構築・操作セット生成後、探索直前にmonotonic_ns（単調時計を整数nsで読む操作）から原点を一回取得する。同じ時計と一つのSearchControl（期限・停止要求の制御データ）を使い、合法予備手準備も予算に含める。入力処理・出力は予算に含めない。
- 既存iterative_deepening.search_controlled（同期探索操作）の最終結果一件を使い、探索内部や将棋規則を複製しない。通常出力は実行条件も含め探索返却後にまとめる。途中表示・途中通知API・スレッドを追加しない。

### 承認済みの表示・状態・中断

- 実行条件はSFEN、開始側視点、指定上限深さと目標/上限ms。終了結果は状態、USIと日本語の選択手、その由来、完了記録の有無。記録ありなら最後の完了深さ・その評価/訪問数・完了反復累計を表示。
- COMPLETEは指定上限まで完了。NO_LEGAL_MOVEは手も記録もなし。STOPPEDは最新完了結果または合法予備手。SUPPRESSEDは選択手なしで記録のみ保持できる。抑制を起こす新引数は作らず、戻り値の表示契約だけを漏れなく定めた。
- 記録なしは評価なし。深さ0/1の架空記録や評価0を作らない。last_completedに手があっても抑制時の選択手へ復活させない。合法手なしを投了や詰みと断定しない。
- STOPPEDから目標/上限のどちらによる停止かを推測しない。既存結果は細かな停止原因を保持しないため。累計へ準備や中断反復を加算しない。訪問回数と実時間・全作業量を同一視しない。
- Ctrl+Cは通常停止要求へ変換して結果を待つ案を採らず、KeyboardInterruptを捕捉し診断・終了130とした。例外で同期探索を抜けても、呼出し側で最新記録を受け取れるとは限らないため。
- mainの解析器作成から最終表示までを中断捕捉範囲とし、探索の再開・request_stop・結果の回収/再表示を行わない。返却前は結果表示なし、返却後の出力中なら部分表示が残り得る。原子的な出力、捕捉ハンドラー自身への再中断等まで保証しない。
- 終了コードは正常結果とヘルプ0、内部故障は原因を保持して例外伝播し通常モジュール実行1、入力不正2、捕捉したCtrl+C130。結果stdout、診断stderr。入力段階だけのValueErrorを2とし、時計・操作セット・探索・整形・出力の内部故障を入力不正にしない。

既存三方式Random（最弱・既定）・一手駒得・現行二手先読み、既存比較コマンドを維持。通常対局・USIへの新方式接続、予算式/設定変更、時間保証、棋力実証、新評価、定跡、置換表は対象外。
