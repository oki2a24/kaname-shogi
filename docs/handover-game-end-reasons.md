## 📚 第35回で確認済みの一次資料

- 日本将棋連盟「対局規則」第6条第1項は、対局が詰みまたは相手の投了によって終了すると定める。
  - 出典: https://www.shogi.or.jp/match/taikyoku_rules/
- 日本将棋連盟「王手と詰み」は、負けを悟った場合に詰む前に投了することが普通だと説明する。
  - 出典: https://www.shogi.or.jp/knowledge/shogi/04.php
- 公式規則の知識をそのまま全て実装するのではなく、今回の学習対象は投了による終局の最小部分に限定する。
