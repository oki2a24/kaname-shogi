# プロジェクトの背景

## はじまり

このプロジェクトは、将棋を知り、身につけたいという思いから始まります。

将棋ソフトのアルゴリズムを理解し、自分で少しずつ作るには、駒の動かし方、対局の流れ、勝敗の考え方といったルールを避けて通れません。プログラムを書くことを入口にしながら、将棋そのものも学んでいきます。

## 息子と将棋

息子は将棋が好きで、自分から見ればとても強い一方、プロを目指すほどの道を選んでいるわけではありません。それでも将棋に向き合っている姿を見ることは嬉しく、もっと強くなることを後押ししたいと感じています。

父親である自分が、将棋を学びながらプログラムを作り、それが少しずつ対局できるようになり、やがて強くなっていく。その過程を息子に見てもらえたら、将棋を通じて一緒に成長する小さな機会になるかもしれません。

このプロジェクトは、強い将棋ソフトを最短で作ることだけが目的ではありません。自分で作れるものを見せること、学ぶ姿勢を共有すること、そして長く楽しめる題材を持つことも大切にします。

## 続け方

最初から完成度や強さを求めません。理解できる小さな段階を積み重ね、できたことを確かめながら進めます。

途中で方針が変わっても構いません。この文書は、何のために始めたかを思い出すための記録です。
