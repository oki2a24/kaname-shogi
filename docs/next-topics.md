# 金の候補生成後：次のテーマ候補

2026-09-20に、桂馬までの実装と日本将棋連盟の説明を確認して更新した。以下はアシスタントの提案であり、実装の合意や固定された開発順序ではない。規模は桂馬までの現在地との相対的な目安。

## 候補の比較

| 候補 | 学ぶ内容・最小範囲 | 規模 | 今選ぶ利点・留意点 |
| --- | --- | --- | --- |
| 玉の移動先候補 | 周囲8方向へ1マス。先後で移動方向の集合が変わらない | 小 | 先後反転を使わない駒を学べる。ただし王手・合法手は別テーマ |
| 空マスへの移動の適用 | 出発・到着の組を表し、出発点を空にして到着点へ駒を置く | 中〜大 | 候補生成から盤面変更へ進める。まず駒取りや手番更新を含めず、失敗時に盤を壊さない設計を学ぶ |
| 成りの基礎 | 敵陣、成り・不成、成った駒の表現 | 中〜大 | 既存の候補生成に関係するが、状態表現の設計が必要。移動適用の後が望ましい |
| 合法手判定の基礎 | 王手、王手放置、候補手と合法手の違い | 大 | 将棋プログラムの重要な段階だが、盤面変更・王の扱いを先に整理する必要がある |

## 推奨

銀の移動先候補は第10回・第11回で学習・実装済みである。次の一回は「玉の移動先候補」を推奨する。周囲8方向へ1マスという、先後で前方を反転しない駒を扱えるため、これまでの方向表現を整理する区切りになる。ただし、王手や合法手判定は別テーマとする。

候補生成を一通り学んだ後は、玉の移動先候補、空マスへの移動適用、成りの基礎、合法手判定の順が考えやすい。新しい状態変更へ進むなら空マスへの移動適用、ルール理解を優先するなら成りの学習を先に相談する。ただし、候補生成と実際の移動を同じテーマに詰め込まない。

次回の導入では、既存の金の関数を実際に読みながら、所有者・6方向・除外・結果の返却を説明する。その後に新テーマの学習へ進む。コードの紹介前に実装全体を把握している前提で質問しない。

成り、駒取りと持ち駒、王手と合法手、探索も将来の候補だが、状態表現や複数の規則にまたがるため、今の小さな候補生成の次に一括実装することは勧めない。
