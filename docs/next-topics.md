# 金の候補生成後：次のテーマ候補

2026-09-14に、現在の歩・金の実装と日本将棋連盟の説明を確認して検討した。以下はアシスタントの提案であり、実装の合意や固定された開発順序ではない。規模は今回の金との相対的な目安。

## 候補の比較

| 候補 | 学ぶ内容・最小範囲 | 規模 | 今選ぶ利点・留意点 |
| --- | --- | --- | --- |
| 銀の移動先候補 | 前と斜め前後の5方向。金との違いを増減表で表す | 小 | 最も無理なく金を復習できる。成銀は別テーマ。共通化は必要性を見て判断する |
| 香の移動先候補 | 前方を1マスずつ調べ、自駒の手前・相手駒のマスで止める | 中 | 距離が一定でない移動と繰り返しの終了を学べる。飛・角への足場になる |
| 桂の移動先候補 | 前へ2段・横へ1筋の2候補。途中の駒を飛び越す | 小〜中 | 飛び越す駒と経路確認の違いを学べる。成りや行き所のない駒の合法性は別に扱う |
| 玉の移動先候補 | 周囲8方向へ1マス。先後で移動方向の集合が変わらない | 小 | 既存の候補生成を復習できる。王手に入らない判定は別であり、合法手とは呼ばない |
| 飛の移動先候補 | 縦横4方向の各方向を、盤外か駒に当たるまで調べる | 中 | 方向と距離の二重の繰り返しを学べる。香を先に扱うと段階を小さくできる。角は別の回 |
| 空マスへの移動の適用 | 出発・到着の組を表し、出発点を空にして到着点へ駒を置く | 中〜大 | 目に見える盤面の変化へ進める。まず金・空の到着点などに限定し、入力の検証、変更の単位、失敗時に盤を壊さない方針を設計する。駒取り・持ち駒・手番更新・合法手判定は同時に詰め込まない |

## 推奨

候補比較後、利用者は次のセッションで「銀の移動先候補」に取り組むと決定した。以下の推奨は選択に至る検討経緯として残す。銀の詳細設計は未着手。再開手順は[銀への引き継ぎ](handover-silver.md)を参照する。

次の一回は銀を推奨する。金と似た処理を本人が読み解く機会を持ち、動きの差を表現できることを優先する。その後、新しい処理を学びたければ香へ進むと、1方向の距離走査から飛・角の複数方向へ段階的に広げられる。

次回の導入では、既存の金の関数を実際に読みながら、所有者・6方向・除外・結果の返却を説明する。その後に新テーマの学習へ進む。コードの紹介前に実装全体を把握している前提で質問しない。

成り、駒取りと持ち駒、王手と合法手、探索も将来の候補だが、状態表現や複数の規則にまたがるため、今の小さな候補生成の次に一括実装することは勧めない。
