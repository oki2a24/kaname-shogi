  - `SearchControl`はgo読取り時点の整数nsを受け、整数の目標/上限期限を判定する。起動時へ原点を置き換えないのは受渡し・回収待ちも予算へ含めるため。

  - 誤り注入で外側確認に隠れた詰み中断の通常点化・応手への根保護流用の検出不足を発見し、下位結果を直接観測するテストで補強した。詳細は[実装記録](learning/search-stop-implementation-plan.md)。
