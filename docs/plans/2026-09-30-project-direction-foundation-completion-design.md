# プロジェクトの方向性にある基盤整理の完了状態：設計仕様

## 目的

`docs/02-project-direction.md` に残る「現在はリポジトリ基盤を整理する小テーマを進めている」
という現在情報を、基盤整理の完了後の状態と一致させる。

## 対象と非対象

### 対象

- 「最初のゴール」節にある現在情報の一文だけ

### 非対象

- 段階的な発展の見通し、将来のSFEN・USI・探索・評価の方針
- 第32回から第42回までの「完了時点の見直し」という履歴
- `docs/next-topics.md`、ロードマップ、再開案内、学習記録
- コード、テスト、CLI動作、将棋規則、保存形式

## 変更する表現

次の現在情報を置き換える。

```text
この最初のゴールは、第42回までに達成しました。現在は、次の機能追加の前にリポジトリ基盤を整理する小テーマを進めています。
```

置換後は次のとおりとする。

```text
第42回までに最初の到達点を完了し、その後のリポジトリ基盤整理も完了した。現在は、次テーマを選ぶ前の段階にある。
```

「第42回までに」は最初のCLI到達点の完了時点を表し、「その後」は第43回から第50回で
完了した基盤整理を表す。次テーマを未選定とする現在情報は、`docs/next-topics.md` と
`docs/resume.md` の記録と一致する。

## 確認方法と記録

差分が `docs/02-project-direction.md` の対象1文だけであり、過去の見直し節とコード・
テストに差分がないことを確認する。対象文書の相対Markdownリンク、`git diff --check`、
全ユニットテストを実行する。

実施内容と検証は、この設計仕様に対応する実装計画へ記録する。将棋規則や実装上の確定知識は
増えないため、`docs/knowledge/` と学習記録は更新しない。
