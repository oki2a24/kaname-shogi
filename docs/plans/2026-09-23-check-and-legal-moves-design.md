# 王手と合法手判定：設計仕様

作成日：2026-09-23

## 目的と範囲

盤上移動 `apply_move` と駒打ち `apply_drop` が、指した直後に自分の玉が相手の
利きに入る手を拒否できるようにする。玉が相手の利きにある状態を王手と呼び、
王手を防がない手、相手の利きへ玉を動かす手、遮っていた駒を動かして自玉を
相手の飛車・角・香の利きへさらす手を合法手から除く。

日本将棋連盟は王手を「次に玉を取ろうとする手」と説明し、王手を受けた側は
玉を逃がすなどして防がなければならないとしている。また、王手放置および
相手の駒の利きに自玉を動かすことを反則としている。
[日本将棋連盟「王手と詰み」](https://www.shogi.or.jp/knowledge/shogi/04.php)
、[対局規則 第10条](https://www.shogi.or.jp/match/taikyoku_rules/)

今回扱うのは王手の検出と、盤上移動・駒打ちにおける自玉の安全確認である。
打ち歩詰め、詰み・終局判定、反則時の勝敗、合法手の全列挙、CLI入力、履歴、
評価、探索は扱わない。相手玉へ王手をかける手自体は許可する。

## 独立した局面の複製

`Board.copy()`、`Hand.copy()`、`Position.copy()` を公開する。いずれも元の状態を
変更せず、独立した可変状態を持つ複製を返す**操作**である。

- `Board.copy()` は81マスを入れた新しい内部リストを持つ `Board` を返す。
- `Hand.copy()` は持ち駒枚数を入れた新しい内部辞書を持つ `Hand` を返す。
- `Position.copy()` は `board.copy()` と先後それぞれの `hand.copy()` を使い、同じ
  `side_to_move` を持つ新しい `Position` を返す。

`Square` と `Piece` は変更不可の**値**なので、盤の各マスに入る同じ値を複製先と
共有してよい。一方、`Board` のマス列、`Hand` の枚数辞書、`Position` の参照先は
可変の**状態**であるため共有しない。これにより複製局面での試し指しは本物の
局面へ影響しない。

## 王手の判定

`is_in_check(board, side)` を `movegen.py` の公開する**判定操作**として追加する。
指定した `side` の玉を盤上から探し、相手側の各駒について既存の
`_move_candidates_for_piece` を求め、その候補に玉のマスがあれば `True` を返す。
そうでなければ `False` を返す。盤面と持ち駒は変更しない。

移動候補は自駒を越えて進めず、相手駒のマスを候補に含めるため、飛車・角・香の
遮蔽、桂馬の飛び越し、成駒を含む全14種類の利きを、既存の候補生成の意味に
そろえて利用できる。

既存の単体テストでは、特定の操作だけを確認するため玉を置かない部分局面を
使っている。その互換性を保つため、指定側の玉が盤上にない場合は `False` を返す。
通常の対局局面に必ず玉があることを検証する局面整合性や終局処理は今回の範囲外と
する。

## 合法性の確認と局面適用

公開の `apply_move` と `apply_drop` は、既存の通常規則を検証して局面を一手進める
非公開操作へ委譲する。非公開操作には、自玉の安全を追加検証せず局面を適用する
内部用の引数または等価な分離を設ける。これにより試し指しから公開操作を再帰的に
呼び出さない。

公開操作は次の順で動く。

1. `position.copy()` で試し指し用の独立局面を作る。
2. 既存の成り、候補、所有者、駒取り、二歩、行き所のない駒、持ち駒不足などを
   非公開操作で試し指し用局面へ適用する。既存規則に反すれば本物を変更せず
   `ValueError` とする。
3. 試し指し後に、指した側の玉について `is_in_check` を呼ぶ。王手なら本物を
   変更せず `ValueError` とする。
4. 王手でなければ同じ非公開操作を本物の局面へ一度だけ適用する。

成功時の盤面、持ち駒、成駒種、手番交代は既存どおりとする。拒否時は盤面81マス、
先後双方の持ち駒、手番を変更しない。王手を受けた局面では、玉の退避、王手駒の
取得、飛車・角・香の直線王手に対する合い駒のうち、試し指し後に自玉が安全となる
手だけを許可する。桂馬の王手は合い駒で防げない。

## テスト方針

- `Board.copy`、`Hand.copy`、`Position.copy` について、複製後の盤面・持ち駒・手番が
  同じであり、複製先だけを変更しても元の局面へ影響しないことを確認する。
- 玉への各駒種の利きを含め、王手・非王手、遮蔽、成駒、先後双方の
  `is_in_check` を確認する。
- 盤上移動での王手放置、相手の利きへの玉移動、自ら遮蔽を外す移動を拒否し、
  局面が不変であることを確認する。
- 玉の退避、王手駒の取得、飛車・角・香への合い駒を許可し、桂馬への合い駒を
  拒否することを確認する。
- 駒打ちで王手放置を拒否し、王手を遮る合い駒を許可することを確認する。
- 既存の成り・駒取り・二歩・行き所のない駒と、部分局面（自玉なし）の既存の
  振る舞いを保つことを確認する。
- 対象テスト、全テスト、CLI、`git diff --check` を実行する。

## 実施しないこと

打ち歩詰め、詰み・終局、合法手の一覧を返す操作、局面に玉が一枚ずつ存在するかの
整合性検証、CLI入力、履歴、評価、探索は含めない。今回の `is_in_check` は王手を
読む判定だけであり、勝敗を決めない。

## 仕様の自己レビュー

- 盤上移動と駒打ちの両方を対象にしている。
- 可変状態を共有しない複製の範囲と、不変値を共有できる理由を明記した。
- 王手の検出、試し指し、失敗時不変、部分局面の扱いを明記した。
- 打ち歩詰め・詰み・終局などの今回扱わない範囲を分離した。
