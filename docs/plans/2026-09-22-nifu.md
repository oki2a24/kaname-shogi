**目標:** 持ち歩を打つとき、同じ筋に手番側の未成の歩があれば二歩として拒否し、局面を変更しないようにする。

**アーキテクチャ:** `kaname_shogi.movegen` に、指定筋の指定側の未成の歩を盤面から読む非公開判定 `_has_unpromoted_pawn_on_file` を置く。既存の公開操作 `apply_drop` は、歩を打つ場合だけこの判定を持ち駒の減算より前に呼び、二歩を `ValueError` で拒否する。`Hand`、`Board`、`Position` の責務と公開インターフェースは変えない。

**技術スタック:** Python 3、標準ライブラリ `unittest`、既存の `dataclasses` と `Enum`。

**仕様 (Spec):** `docs/plans/2026-09-22-nifu-design.md`、設計の正本は `docs/design/15-nifu.md`。

**グローバル制約 (Global Constraints):**
- 持ち歩を打つとき、同じ筋に手番側の未成の歩があれば二歩として拒否する。
- 二歩では `ValueError` とし、盤面・手番・先後双方の持ち駒を変更しない。
- 同じ筋にと金だけがある場合は二歩ではない。ただし現在は成り状態が未実装のため、実装上は `PieceType.PAWN` を未成の歩として判定する。
- 行き所のない歩・香・桂、打ち歩詰め、成り・不成、王手・合法手、CLI入力は扱わない。
- テストメソッド名は英語とし、日本語docstringの先頭行に確認する振る舞い、続く本文に検出したい誤りや背景を書く。

`ApplyDropTests` に次のテストを追加する。先後それぞれで、空の５五へ持ち歩を打とうとする前に、同じ５筋の別段へその側の歩を置く。拒否後は既存の `_assert_position_unchanged` で81マス・双方の持ち駒・手番を検証する。また、５筋に先手歩があるとき、先手の銀を５五へ打てることも確認する。

```python
def test_rejects_double_pawn_without_changing_position(self):
    """同じ筋に自分の歩がある持ち歩打ちを拒否し、局面を変更しない。

    相手の歩を誤って数えること、持ち駒を先に減らすこと、例外時に手番を交代する
    ことを、先手・後手の両方で検出する。
    """
    for side, pawn_rank in ((Side.SENTE, 7), (Side.GOTE, 3)):
        position = Position(Board(), side)
        hand = (position.sente_hand if side == Side.SENTE
                else position.gote_hand)
        hand.add(PieceType.PAWN)
        position.board.set_piece(Square(5, pawn_rank),
                                 Piece(PieceType.PAWN, side))
        squares = [Square(file, rank) for file in range(1, 10)
                   for rank in range(1, 10)]
        before_board = [position.board.piece_at(square) for square in squares]
        before_hands = self._hand_counts(position)
        with self.subTest(side=side):
            with self.assertRaises(ValueError):
                self._apply_drop(position, PieceType.PAWN, Square(5, 5))
            self._assert_position_unchanged(position, before_board,
                                            before_hands, side)
```

```python
def test_allows_non_pawn_drop_on_file_with_own_pawn(self):
    """同じ筋に自分の歩があっても、銀の打ちは二歩として拒否しない。

    二歩の制限を歩以外の駒打ちへ誤って広げることを検出する。
    """
    position = Position(Board(), Side.SENTE)
    position.sente_hand.add(PieceType.SILVER)
    position.board.set_piece(Square(5, 7),
                             Piece(PieceType.PAWN, Side.SENTE))
    self.assertIsNone(self._apply_drop(position, PieceType.SILVER,
                                       Square(5, 5)))
    self.assertEqual(position.board.piece_at(Square(5, 5)),
                     Piece(PieceType.SILVER, Side.SENTE))
```

`apply_drop` の直前に、打ち先の筋の1段から9段を読む判定を追加する。`apply_drop` では、玉・占有マスの既存検証後、持ち駒を減らす前に歩だけを判定する。二歩なら `ValueError` とする。docstringの例外と非対象の説明を二歩実装済みに更新する。

```python
def _has_unpromoted_pawn_on_file(board: Board, side: Side, file: int) -> bool:
    """sideの未成の歩がfile筋にあればTrueを返し、盤面を変更しない。"""
    for rank in range(1, 10):
        piece = board.piece_at(Square(file, rank))
        if piece == Piece(PieceType.PAWN, side):
            return True
    return False
```
