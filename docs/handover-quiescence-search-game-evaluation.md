# 引き継ぎ：静止探索を通常対局で使い、時間と成績を測る

## 最終目標

本人が次の大テーマ候補1を選んだ。静止探索を通常対局で利用できる経路へ接続し、各手の持ち時間に収まるか、取り合いの見落としや対局成績へ影響するかを、条件をそろえた対局で調べる。結果は改善・悪化・判断材料不足に分け、少数局や固定局面の結論を一般棋力へ拡張しない。

候補の選定は、新しい大テーマの選択である。実装方式、接続先、比較条件、調査局数、設計、実装計画は未合意・未承認で、コード・テスト・通常対局の変更は始めていない。次のセッションで一問ずつ設計し、作業方針に従って実装計画を示し、本人の明示承認後にだけ実装へ進む。

## 選定の背景・完了事項

- 旧主線「駒得以外の局面評価を育てる」は本人判断で一区切り。次の広い方針として、本人は研究論文から手法を選び、全体像と具体例を学び、実装し、対局成績で効果を測る進め方を選んだ。
- その最初のテーマ「水平線効果への対策」では、佐藤佳州・高橋大介「モンテカルロ木探索によるコンピュータ将棋」の本文全体を確認した。4.3節だけを抜き出して逆効果や誤読にならないよう、論文の構成、試し指し・UCT、将棋向け手法、問題集と実戦の結果、静止探索との組み合わせ、定跡と終盤例を順に検討した。静止探索の詳細は本文で足りなかったため、公式YaneuraOuの固定コミット `3a0e4fd2394e40f72fc6e2ad5aada832b4045cd9` の探索・手生成コードを参考資料として確認した。論文の勝率を要将棋の効果へ読み替えてはいない。
- 設計した候補 `baseline` は末端追加なし、`q2` と `q4` は通常深さ4の各末端から静止探索を追加最大2手・4手行う。これは全合法手を通常深さ8まで読む意味ではない。王手でない局面では静的評価（stand pat）を基準に捕獲手を調べ、王手中は合法な王手回避を調べる。静止探索の追加手数上限で未完了となった結果は完了反復として扱わず、最後に完了した通常探索結果へ戻す。
- Task 1〜4として、制御付き探索の末端契約、将棋用静止探索、反復深化への接続、小局面診断コマンドを実装・検証した。診断コマンドは開発用で、通常CLI・USI・対局には接続していない。
- 比較診断は固定した玉だけの局面と捕獲局面で、3方式を各時計条件から一回ずつ実行した。q2は捕獲局面で深さ3の静止探索上限に達した一方、baselineとq4は深さ4を完了した例がある。これは局面を限った一回の診断で、一般的な速度・強さの証拠ではない。
- 現行AlphaBeta4を通常CLIの10分30秒で20手観察した記録では3手が深さ4完了、17手が通常停止。別の6手の深さ診断では、3手が深さ4完了、3手が深さ3で停止した。これは静止探索を追加していないAlphaBeta4の観察であり、ShogiHomeでの元の対局は再現・照合していない。
- 最後の理解確認で本人は「今回作ったやつに十分な時間が当てられるかどうか不明なため」と回答した。単一局面の実行結果だけでは、実戦で各手の時間に収まることも、一局全体の成績に寄与することも分からない。時間余裕と対局成績は次のテーマで初めて調べる。
- 旧主線からの保留は「成りに近づく進行度」と比較CLI全量30分目標。別の実践保留はShogiHomeでのU候補対局。これらを今回のテーマの必須条件に加えない。

詳細な本人回答・設計・Task別実績・検証限界は[静止探索の学習記録](learning/quiescence-search.md)、承認済み仕様は[設計書](plans/2026-11-07-quiescence-search-design.md)と[実装計画](plans/2026-11-07-quiescence-search-implementation-plan.md)を参照する。
