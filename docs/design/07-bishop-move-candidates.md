# 角の移動先候補：設計

## 設計の目的

飛車で学んだ複数方向の走査を、角の斜め4方向へ適用する。今回の対象は盤上の成る前の角についての移動先候補であり、実際の移動や合法手の確定ではない。

## 対象範囲

扱うものは、盤面と出発マスから角の移動先候補を求める処理である。成り、馬の動き、実際の移動、駒取り、持ち駒、王手、合法手判定、手番による制限は扱わない。

## 公開インターフェース

```python
bishop_move_candidates(board, source)
```

- `board`：駒の配置を持つ盤面データ。
- `source`：角の出発マスを表す `Square` の値。
- 戻り値：近いマスから固定した方向順で格納した、新しい候補リスト。
- 副作用：盤面を変更しない。駒を動かしたり取ったりしない。
- 前提：出発マスには成っていない角を置く。空または角以外なら `ValueError`。

## 候補順と方向表現

方向順は、盤面表示上の「右前 → 左前 → 右後ろ → 左後ろ」とする。READMEの表示は左から9筋、…、1筋なので、右は筋−1、左は筋＋1である。前後の段の増減は出発駒の所有者から決める。

| 方向 | 筋 | 段 |
| --- | --- | --- |
| 右前 | −1 | 先手−1、後手＋1 |
| 左前 | ＋1 | 先手−1、後手＋1 |
| 右後ろ | −1 | 先手＋1、後手−1 |
| 左後ろ | ＋1 | 先手＋1、後手−1 |

各方向を出発マスから1マスずつ調べ、方向ごとに近い候補から結果へ追加する。

| 調べたマス | 候補への追加 | その方向の走査 |
| --- | --- | --- |
| 盤外 | 追加しない | 終了 |
| 空マス | 追加する | 継続 |
| 自駒のマス | 追加しない | 終了 |
| 相手駒のマス | 追加する | 終了 |

## 実装方針

角専用関数の中で、4方向の筋・段の増減を順に取り出し、同じ走査処理を行う。飛車との共通ヘルパーは今回作らない。角の学習範囲を保ち、飛車と角の違いを方向データとして直接読めるようにするためである。実装後に共通化の必要性だけを点検する。

## 確認方法

次の振る舞いを `unittest` で確認する。

- 空マス・角以外の出発点を `ValueError` とする。
- 開いた盤面で斜め4方向を固定順・近い順に返す。
- 自駒の手前で停止し、自駒とその先を候補に含めない。
- 相手駒のマスを候補に含め、その先を候補に含めない。
- 1方向の停止が他方向の候補計算を妨げない。
- 四隅で盤外へ出ず、先後どちらでも同じ斜め方向の集合を返す。
- 候補計算後も盤面の全81マスを変更しない。
- 呼び出しごとに独立した候補リストを返す。
- `Position.side_to_move` によって候補を制限せず、出発駒の所有者から前後を決める。

テストメソッド名は英語とし、日本語docstringで確認する振る舞いと背景を記録する。
