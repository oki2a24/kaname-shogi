# ShogiHomeのSFEN連携と時計条件

ShogiHomeとUSIエンジンの接続確認では、画面への棋譜・局面貼り付けと、エンジンへUSI `position sfen` が送信された事実を分けて扱う。送信は対象セッションの通信ログ、応答は `bestmove` と棋譜・盤面で確かめる。

ShogiHome 1.28.1のローカル対局は、持ち時間と秒読みを両方0にすると「持ち時間と秒読みが両方とも0です」と開始を拒否する。時計なしの開始を前提にせず、0設定で拒否されたら停止する。ユーザーが時計ありへ変更した場合は、承認済みの時間を画面で確認する。10分＋秒読み30秒はこの環境で実際に開始できた。

このShogiHome版で4欄SFENを新規棋譜として貼り付けた一例では、表示上の局面と後手番は保たれたが、USIログの `position sfen` の手数欄は入力の `4` でなく `1` だった。手数欄が保たれると仮定せず、必要な場合は別途検証する。

USI通信ログ設定の変更はアプリ再起動後に有効になる。未保存棋譜を残すため設定をOFFにして再起動しない場合、現在のアプリプロセスではログ出力が続く。次の再起動まではUSIエンジンを起動しない。詳細な実測値は [ShogiHome接続の確定知識](../../docs/knowledge/usi-shogihome-gameplay.md) と [第69回記録](../../docs/learning/69-shogihome-sfen-engine.md) を参照する。
